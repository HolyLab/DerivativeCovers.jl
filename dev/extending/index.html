Programs and new operations

Writing a program

The functions that take a program f and a point x0 call f on a vector of TVars, which record each operation on a Tape (or, for forward_cover, on a vector of FVars, which propagate the cover as the program runs). f must therefore be written generically, and use only the supported operations:

  • arithmetic: +, -, *, /, inv, and ^ (with a constant or variable exponent);
  • functions: abs, abs2, sqrt, exp, log, sin, cos, tan, tanh, and atan;
  • array operations: sum, dot, and matrix-vector and matrix-matrix products, which record one operation per entry of the result rather than a sequence of scalar operations.

Constants, including typed literals such as zero(eltype(x)), are folded into the operations that use them and take no space on the tape.

Comparisons are not defined for TVar. To branch on the value of a variable, compare its underlying value, obtained with value:

julia> using DerivativeCovers

julia> f(x) = DerivativeCovers.value(x[1]) > 0 ? x[1]^2 * x[2] : -x[1] * x[2];

julia> round.(cover_hessian(f, [1.0, 2.0]).h_sum; digits=4)
2-element Vector{Float64}:
 4.8284
 0.7071

The cover then describes the branch taken at x0.

Recording a tape

tape_function records a program and returns the tape and the index of the output node (or a vector of indices, for a vector-valued program). The tape can also be recorded by hand:

julia> t = Tape([0.5, 2.0]);

julia> x = [TVar(t, i) for i in 1:t.ninputs];

julia> y = exp(x[1]) + x[1] * x[2]^2;

julia> DerivativeCovers.nnodes(t)
6

The element type of the tape, eltype(t), sets the precision of the whole computation. It defaults to float(eltype(x0)); use Tape{Float32}(x0) to record in another precision.

Adding an operation

A new scalar operation is added by computing its value and its first and second derivatives and passing them to one of the recording functions unarynode or binarynode. Defining the method for CoverVar, the supertype of TVar and FVar, makes the operation available to both the tape and forward_cover:

julia> function Base.log1p(x::DerivativeCovers.CoverVar)
           v = DerivativeCovers.value(x)
           return DerivativeCovers.unarynode(x, log1p(v), 1 / (1 + v), -1 / (1 + v)^2)
       end;

julia> g(x) = log1p(x[1] * x[2]);

julia> round.(cover_hessian(g, [0.5, 2.0]).h_sum; digits=4)
2-element Vector{Float64}:
 2.4142
 0.6036

Operations with more than two arguments and structured second derivatives are recorded with pushnode!, which takes the second derivatives as a Curvature. The docstring of Curvature lists the methods a new form must implement. dotnode and linearnode record inner products and linear combinations.

Declaring a sub-map

A part of the program that maps several values to several others can be recorded as a single operation per output, described by a declaration: the values of its outputs, its exact Jacobian, and a cover of the Hessian of each output. The tape then records the declaration instead of the operations inside the part.

Suppose the program passes two intermediate values through a map F from $\mathbb{R}^2$ to $\mathbb{R}^2$. submap(F, xs) evaluates F on the arguments xs, computes the declaration, and records it on the tape of xs, returning the outputs of F:

julia> using DerivativeCovers

julia> F(v) = [v[1] * exp(v[2]), v[1]^2 + v[2]^2];

julia> function outer(x)
           y = DerivativeCovers.submap(F, [x[1] + x[2], x[3]])
           return y[1] * y[2] + x[1]
       end;

julia> x0 = [0.3, 0.2, -0.4];

julia> round.(cover_hessian(outer, x0).h_sum; digits=4)
3-element Vector{Float64}:
 3.2057
 3.2057
 2.6541

declare_submap computes the same declaration without recording it. Here the arguments of F at x0 are [0.5, -0.4]:

julia> d = DerivativeCovers.declare_submap(F, [0.5, -0.4]);

julia> round.(d.J; digits=4)     # J[k, i] is the derivative of output k with respect to argument i
2×2 Matrix{Float64}:
 0.6703   0.3352
 1.0     -0.8

julia> round.(d.S; digits=4)     # row k is a cover of the Hessian of output k
2×2 Matrix{Float64}:
 1.1579  1.1579
 1.4142  1.4142

submapnode records a declaration supplied by the caller. This allows a part of the program that cannot be recorded, such as a call to an external library, to appear on the tape, provided that its Jacobian can be computed and its second derivatives bounded by other means. Covers computed from the tape are valid provided that the declaration is. Because the exact second derivatives are not recorded, hvp is not available on a tape that contains a declared sub-map.

Combining covers of pieces

When a program is a composition F₂ ∘ F₁ and covers of the two pieces are available separately, compose_jacobian_cover combines Jacobian covers of F₁ and F₂ into a cover of the Jacobian of the composition, and compose_hessian_cover combines covers of the derivatives of F and g into a cover of the Hessian of g ∘ F:

julia> using DerivativeCovers

julia> F1(x) = [x[1] * x[2], x[1] + x[2]];

julia> F2(y) = [exp(y[1]) * y[2]];

julia> x0 = [0.5, 2.0];

julia> y0 = [x0[1] * x0[2], x0[1] + x0[2]];

julia> c1 = cover_jacobian(F1, x0); c2 = cover_jacobian(F2, y0);

julia> a, b = DerivativeCovers.compose_jacobian_cover(c2.a, c2.b_sum, c1.a, c1.b_sum);

julia> J = jvp(x -> F2(F1(x)), x0, [1.0, 0.0])[1], jvp(x -> F2(F1(x)), x0, [0.0, 1.0])[1];

julia> all(abs.(collect(J)) .<= a[1] .* b)
true

This requires no joint recording of the two pieces, so the pieces can be covered by different means or over different regions (see Covers over a box).
