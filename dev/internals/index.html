Internals

This page documents the sweeps, partitions, and intermediate quantities used to implement the public API. They can be called with the DerivativeCovers. prefix, but they are not part of the supported API and may change without notice.

DerivativeCovers also adds methods for recorded tapes to several functions of MatrixCovers, such as gramcover. Those functions belong to MatrixCovers, so load that package to call them without qualification.

DerivativeCovers.DeclaredScales — Type
DeclaredScales(w, t)

The two node channels a block may ask for beyond the values: sensitivity_scales seeded with the input scales w, and the live_nodes flags. Each is built by the first block that asks for it and shared by every block after. nguarded counts the blocks whose split read the scales (see note_guarded).

Deferring the sweeps is what makes them free on a program that never needs them. Deciding in advance would take its own O(L) pass over the recorded blocks, which on a tape whose blocks all keep a usable value pair costs about as much as the cover sweep it precedes — so every program would pay for the possibility of a fallback none of its blocks reach.

DerivativeCovers.ExpScaled — Type
ExpScaled{F}(m, e=0)
ExpScaled(x::AbstractFloat)

The real number m * 2^e, stored as a significand of type F <: AbstractFloat and an Int exponent. It has the precision of F and an exponent range limited only by Int, so products and sums of positive values never underflow to zero or overflow to Inf.

Wherever the exact result of an operation is a normal number of F, +, -, *, /, sqrt and hypot round to the same value F would give: the significand is computed in F, and scaling by a power of two does not change how a normal number rounds. Results below F's normal range or above its largest value keep full precision instead. Conversion back to F rounds once, saturating to zero or Inf outside F's range.

The significand is held in frexp form: 0.5 <= abs(m) < 1 for a finite nonzero value, and the exponent is 0 for zero and for non-finite values, which carry their F value in m. An exponent that would leave the range of Int is an OverflowError.

Examples

julia> x = DerivativeCovers.ExpScaled(1.0e-300)^2
DerivativeCovers.ExpScaled{Float64}(0.8969771056830114, -1993)

julia> Float64(x), Float64(sqrt(x))
(0.0, 1.0e-300)

DerivativeCovers.ForwardChannels — Type
ForwardChannels{T, S, M, SM}

The two vector channels an FVar carries beyond its value and its declared scale: the intermediate gradient g = ∇v (storage S, entries T), and the squared cover G (storage SM, entries M = boundtype(T)) maintaining sqrt.(G) * sqrt.(G)' >= magnitude.(∇²v) entrywise.

G is squared rather than rooted because the recursion that maintains it is linear in the parents' G, which is what keeps a per-node re-merge from compounding with depth.

The channels live in the FVar's own fields; channels assembles this view of them on demand, and it costs nothing once inlined.

DerivativeCovers.ForwardContext — Type
ForwardContext{T, S, M, SM}

State shared by every variable in a forward propagation: the degeneracy threshold local covers split at, whether each local cover is verified, the scratch a node writes through while assembling its cover, and nguarded, the number of blocks so far whose split fell back on the declared scales (see note_guarded).

S is the storage of the intermediate-gradient channel, one entry of T per input, and SM that of the cover channel, one entry of M = boundtype(T) per input. forward_cover derives both from the point it is given, so a Vector input propagates in Vectors and a StaticVector input in StaticVectors. zerogradient and zerochannel are zeros of the two storages, which fresh channels are copied from; the input variables share zerochannel as their cover channel. scratch is the atom accumulator, written in place when SM is mutable and left alone when it is not; and eta holds the slot weights of the elemental being covered.

It is a reference type so that every variable of the propagation holds a pointer to the one context: storing an immutable into a variable's field would copy it, at one allocation per node. Identity is then also what === compares, which is what distinguishes two propagations.

DerivativeCovers.ForwardScale — Type
ForwardScale(sigma, live, ctx)

The declared channel of one slot of a forward propagation: the scale sigma that stands in for a parent value carrying none, whether the slot's intermediate gradient is identically zero, and the ForwardContext that counts the blocks whose split reads sigma (nothing for a constant, whose slot is never split).

sigma is a sum of products of first partials, held in ExpScaled so that a long chain of small factors cannot underflow it to zero while the intermediate gradient it bounds is still there. The liveness flag is carried by the same recursion live_nodes runs over a tape — a slot is live when some parent is live and reaches it through a nonzero partial — so both backends decide which entries to drop by the same test on the recorded partials. With positive input scales, sigma > 0 exactly when the flag is set.

DerivativeCovers.MaxMerge — Type
MaxMerge <: MergeRule

b_j = max_k Ũ_kj/a_k, the exact minimal b for the given a. Non-smooth, so its marginal alternation can settle into a limit cycle: the weights keep changing by a fixed amount every round, which no larger budget reduces. balance_cover reports that as a stall.

source
DerivativeCovers.MergeRule — Type
MergeRule

How balance_cover's b-step combines a column of the scaled surrogate into one input weight: given the entries Ũ_kj/a_k over the outputs k, it returns b_j. Every rule that dominates each of its terms yields a valid cover, so the choice trades tightness, never validity.

SumMerge, QuadMerge and MaxMerge are the p = 1, 2, ∞ members of one family, so a parameterized member (a p-norm merge) is reachable through the same b-step without an API break. They are types rather than names so that the b-step's doubly-nested loop specializes on the choice, and so that the non-convergence hint can dispatch per rule.

SignAveragedMerge is the exception: it runs the whole alternation, not only the final b-step, in quadrature on R, and the pair it returns is a sign-averaged cover, which does not cover J.

arule, the other strategy axis of balance_cover, is a Symbol instead, because it is closed: see that function's docstring.

QuadMerge <: MergeRule

DerivativeCovers.SignAveragedMerge — Type
SignAveragedMerge <: MergeRule

The sign-averaged pair: balance_cover's marginal iteration run in quadrature on R (quadrature_surrogate),

a_k ← sqrt((1/r_k) ∑_j R_kj² / b_j²),    b_j ← sqrt((1/c_j) ∑_k R_kj² / a_k²),

followed by the final b-step b_j = sqrt(∑_k R_kj² / a_k²). Squared, this is the SumMerge alternation applied to the squared channel Ũ⁽²⁾ = R.^2 with factors (a², b²), the same targets and round budget, and the squared start. The iteration works with a, b and R themselves and accumulates every sum of squares with hypot, so it never forms the square of a Jacobian-scale quantity, and the pair is representable wherever the plain pair is. On a tape each half-step is one sweep combining local partials in quadrature, so a round costs O(L) and R is never formed; the final b-step equals gramvariance(t, outidxs, w) with w_k = 1/a_k² on the live outputs and zero on the others, where those squares are representable.

The pair is a sign-averaged cover, not a cover of J. The final b-step gives every live column ∑_k R_kj² / (a_k b_j)² = 1, so a_k b_j >= R_kj, which is what check = true verifies. But R <= Ũ, with equality only where an entry has a single path, so a_k b_j can fall below Ũ_kj, and below abs(J_kj) where several paths add with the same sign. If each parent slot's local partial carries an independent, equiprobable sign, R_kj² = E[J_kj²], and at convergence the pair standardizes the signed Jacobian in expectation: the normalized iterate (a, b ./ sqrt.(c)) has expected row sums of squares ∑_j E[J_kj²] / (a_k² b_j² / c_j) = r_k and column sums c_j, and the returned b has expected column sums of squares 1.

DerivativeCovers._flow_targets — Method
_flow_targets(t::Tape, outidxs, li::LiveInfo) -> (r, c)

Row and column targets from the two flow weightings of the live slot graph, mixed so that neither side dominates: r = r_fwd/nrow + r_rev/ncol and c = c_fwd/nrow + c_rev/ncol, with nrow the live output positions and ncol the live inputs. Marginals are linear in the weight matrix, so the mixture is itself the marginal pair of a nonnegative matrix with Ũ's pattern, which is what makes the targets realizable.

Two of the four marginals are constant by construction — forward flow reaches every live node with mass 1, and reverse flow leaves every live input with mass 1 — so only two sweeps run. O(L), forming no matrix; every weight is at most 1, so nothing can overflow. The two totals are 2 each, to roundoff.

_structural_pattern(t::Tape, outidxs, li::LiveInfo) -> P::Matrix{UInt64}

The structural sparsity pattern of Ũ packed 64 inputs to a word: bit (j - 1) % 64 of P[k, cld(j, 64)] is set exactly when output position k reaches input j along a path of nonzero local derivatives. cld(n, 64) integer passes over the tape and m * cld(n, 64) words, both small beside the m * n surrogate this is compared against.

DerivativeCovers.abs_forward — Method
abs_forward(t::Tape, theta::AbstractVector) -> s

One forward sweep in absolute-value arithmetic, the transpose of abs_reverse: s[k] = theta[k] + sum_i abs(∂φ_k/∂v_{p_i}) * s[p_i] over the parents p_i of node k, in tape order. Seeding theta[j] = 1 at a single input j gives, at every node, the absolute sensitivity of that node to input j — the j-th column of the surrogate Ũ read at the output nodes — and the sweep is linear in the seeds, so any weighted combination of inputs costs the same one O(L) traversal.

source
DerivativeCovers.abs_reverse — Method
abs_reverse(t::Tape, Theta::AbstractMatrix) -> Abar

Vector-mode form of abs_reverse: each row of Theta is an independent seed vector over the nodes (columns), and all rows are propagated in one traversal. Abar[:, a] for an input a holds that input's value for every channel. The seeds are nonnegative magnitudes, as group_seeds returns them in boundtype of the tape's element type, and the sweep computes in their type.

source
DerivativeCovers.abs_reverse — Method
abs_reverse(t::Tape, theta) -> abar

One reverse sweep in absolute-value arithmetic: abar[j] = theta[j] + sum_{k : j in P_k} magnitude(∂φ_k/∂v_j) * abar[k].

With theta from local_covers, abar[1:t.ninputs] is the sum-merge cover — the whole merge in a single gradient-cost sweep, because sum_k s_k = sum_j theta[j] * utilde_j is linear in the seeds.

The sweep computes in the element type of theta, so seeds in boundtype give a sweep that rounds as the tape asks.

DerivativeCovers.balance_cover — Method
balance_cover(t::Tape, outidxs; kwargs...) -> (; a, b, iters, delta, roots, nties)
balance_cover(r, x0::AbstractVector; kwargs...)
balance_cover(Utilde::AbstractMatrix; kwargs...)

Output and input weights covering the absolute-sensitivity surrogate: a[k] * b[j] >= Ũ_kj, and so >= abs(J_kj), for every merge except SignAveragedMerge.

By default the weights come from the log-scale start, rounds rounds of a marginal alternation toward row and column targets the sparsity pattern makes realizable, and a final MergeRule b-step for the a those rounds reached. The b-step is what makes the pair a cover, so the result covers whatever the rounds did or did not settle. The accompanying manuscript derives the weighting rules and their convergence; the keywords below say what each one does without it.

Keywords

  • start = :logscale: a least-squares fit of log-scales — on a tape, of the node potentials of tape_potentials; on a matrix, MatrixCovers' unconstrained start (initialize_cover(U; strategy = :unconstrained)). Products on the support then transform exactly under a rescaling of the inputs and outputs — and, on the tape path, the intermediates — at every round count. start = :equal starts at a = 1 instead, which is permutation equivariant at every round count but covariant only in the limit. Both reach the same fixed point.
  • a0: starting weights of your own, positive on every live output and zero on the others. Combining it with an explicit start is an error.
  • targets: :flow (tape default; O(L); maximizes a flow-weighted mean log-tightness, which can be noticeably looser than :support when outputs differ widely in the number of paths reaching them), :support (matrix default; maximizes the geometric-mean tightness of the sum-merge cover; on a tape it costs cld(n, 64) + cld(m, 64) bit passes), an explicit (r, c), or :uniform for unit row and column sums. :uniform needs the pattern to have total support — every nonzero entry on some positive diagonal — and without it the weights drift, separating without bound while every iterate still covers, so a longer run returns a looser cover. Applies to arule = :marginal only, and :flow needs a tape.
  • rounds = 4: run exactly this many rounds, with no convergence test and no error. 0 merges the start as it is, without computing targets, and reports delta = Inf. nothing runs to delta <= rtol instead and throws if maxiter rounds do not reach it; naming maxiter or rtol and no rounds asks for that too. Such a run overrelaxes the alternation toward targets, in log space with a factor adapted to the observed contraction, which reaches the same fixed point in far fewer rounds on slowly converging patterns; a fixed budget always runs the plain rounds.
  • residual = true: whether a fixed budget toward non-uniform targets measures the row-marginal residual of the pair it returns. No round needs that residual, so measuring it takes one sweep beyond the rounds; false skips the sweep and reports delta = Inf. It has no effect on a run to convergence, whose stopping test is that residual, or where delta is the product change, which costs no sweep.
  • maxiter, rtol: bound and tolerance of a rounds = nothing run. maxiter = nothing picks 1000 rounds for arule = :marginal and 10000 for :geomean. Passing maxiter together with a rounds count is an error.
  • merge: the final b-step, SumMerge (default), QuadMerge or MaxMerge. SignAveragedMerge instead runs the whole alternation in quadrature on R and returns a sign-averaged pair, which does not cover J; the matrix form then takes R (quadrature_surrogate) in place of Ũ, and check verifies a_k b_j >= R_kj.
  • arule: :marginal (default) alternates marginal_weights with the b-step; :geomean fits log Ũ_kj ≈ log a_k + log b_j instead and prescribes no targets.
  • root, cgiters: passed to tape_potentials for the tape-potential start. Naming them on a call that does not reach that start is an error.
  • check = true: verify the returned pair against the surrogate.

Returns

a and b by output position and input, iters rounds run, delta the quantity the convergence test applies to (the gauge-invariant product change max_kj |log((a_k b_j)_new/(a_k b_j)_old)|, or the relative row-marginal residual max_k |∑_j Ũ_kj/(a_k b_j r_k) - 1| for non-uniform targets), and roots, nties from tape_potentials when the tape-potential start was used, nothing otherwise. A zero row of Ũ gets a[k] = 0 and a zero column b[j] = 0. With SignAveragedMerge(), delta is measured on the pair itself and R: the product change is that of a_k b_j, and the residual is max_k |sqrt(∑_j R_kj²/b_j²) / (a_k sqrt(r_k)) - 1|.

Cost

The tape form with merge = SumMerge() or SignAveragedMerge() and arule = :marginal runs as O(L) sweeps and never forms Ũ. After the start and the targets, a budget of rounds >= 1 toward non-uniform targets takes 2 * rounds + 1 sweeps, one more with residual = true: the last round's column sweep is also the final b-step. Every other combination, and check = true, forms Ũ (or R) at O(m*L).

Examples

julia> r(x) = [x[1] * x[2], exp(x[1]) - x[3], x[2] + 2x[3]];

julia> bal = DerivativeCovers.balance_cover(r, [0.5, 2.0, -1.0]);

julia> jc = cover_jacobian(WithDiagnostics(), r, [0.5, 2.0, -1.0]; a = bal.a);

julia> bal.iters, all(jc.b_max .<= bal.b)
(4, true)

DerivativeCovers.balanced_split — Method
balanced_split(c11, c12, c22, zeta1, zeta2) -> (eta1, eta2)

Rank-1 cover of an off-diagonal-active 2×2 block [c11 c12; c12 c22], which requires c12^2 > c11*c22 (see offdiag_active). Returns eta1 >= sqrt(c11) and eta2 >= sqrt(c22) with eta1*eta2 == c12: the cover is exactly tight on the off-diagonal, so no cover of the block is smaller in both entries.

Those constraints leave a one-parameter family. The scale references zeta1, zeta2 — one per parent, supplied by split_block: the parent value magnitudes wherever they carry a scale, the weighted absolute sensitivities where they do not — pick a member, giving eta_i the units of sqrt(f)/[v_{p_i}] and making the cover scale-covariant. The result is continuous in all five arguments except where a vanishing scale reference meets a degenerate block; see the extended help.

Extended help

The three constraints confine eta1 to the segment [sqrt(c11), c12/sqrt(c22)] — nonempty precisely because c12^2 > c11*c22 — and fix eta2 = c12/eta1. Every returned cover lies on this segment, which is what makes it entrywise unimprovable: a competitor smaller in both entries would have eta1*eta2 < c12.

The position along the segment is the point that equalizes the value-weighted scales, eta1*zeta1 == eta2*zeta2, clamped to the segment when that point falls outside. Covariance follows: under a rescaling v_i -> lambda_i*v_i of the intermediate variables, c_ij -> c_ij/(lambda_i*lambda_j) and zeta_i -> lambda_i*zeta_i, so both endpoints and the equalizing point scale as 1/lambda_1; clamp is positively homogeneous, so eta_1 -> eta_1/lambda_1 and eta_2 -> eta_2/lambda_2.

Clamping is also what keeps the result continuous as a parent value vanishes: the equalizing point runs off to an endpoint, and the endpoint absorbs it. Nothing computes those limits separately, because floating-point arithmetic already carries them. sqrt(c12*zeta2/zeta1) is Inf at zeta1 == 0 and 0 at zeta2 == 0, which clamp resolves to the upper and the lower endpoint; c12/sqrt(c22) is Inf at c22 == 0, placing the upper endpoint there. Only zeta1 == zeta2 == 0 leaves a NaN that no clamp resolves, and that is what reaches the fallback.

That reasoning needs the endpoint being approached to be a positive finite scale, and it is not when the corresponding diagonal entry vanishes: c22 == 0 puts the upper endpoint at infinity, c11 == 0 puts the lower endpoint at zero. Nor is there any limit to take when both values vanish at once, since the equalizing point then depends on the ratio zeta2/zeta1 alone. In those cases the geometric mean of the endpoints is used, which is covariant and permutation-equivariant.

So the result is continuous except at three families of inputs, where it is the ratio zeta2/zeta1 that carries the information and the ratio is unavailable:

  • zeta1 == 0 with c22 == 0,
  • zeta2 == 0 with c11 == 0,
  • zeta1 == zeta2 == 0, for any block.

A multiplication node with a vanishing operand has c11 == c22 == 0 and meets all three at once. Among the other elementals of overloads.jl, a quotient u/w meets the first at u == 0, since c22 = 2u/w^3 vanishes with the numerator, and x^y meets the second at a zero exponent, where c11 == 0 and zeta2 == 0 while c22 > 0.

The continuity above is continuity in the values with the block held fixed. At those two elementals the block moves with the value: the diagonal entry that bounds the feasible segment is proportional to the vanishing value, so the endpoint the clamp settles on moves too, and the seed of the slot whose value vanishes grows like |value|^(-1/2). The split stays covariant and valid, but the cover grows without bound as the value approaches zero while the derivatives it covers stay finite, and at the zero itself the block falls into the families above and the cover jumps to a finite one.

These zero-reference cases concern the value channel, and they are exactly the ones value_bounds_split detects: split_block substitutes the declared scales there. The declared scales are propagated in ExpScaled, which neither underflows nor overflows, so a declared scale vanishes only at a slot whose intermediate gradient is zero, which cover_slots! covers diagonally instead of splitting, and is finite wherever the partials are. So a split reaches this function with a pair that is not degenerate.

A declared pair is an ExpScaled pair, and c12*zeta2/zeta1 is then computed with separated exponents, so the equalizing point is found before it is rounded to the cover's element type. A value pair is in the element type, and reaches the geometric mean only when c12*zeta2/zeta1 leaves that type's range at a block whose feasible segment has a degenerate endpoint. There the equalizing point is recomputed from the separated exponents; see split_fallback.

The point found that way can still lie outside the element type's range. A product of many factors does this: its declared scale can lie far below the smallest Float64, and [0 c; c 0] against references (2^-6000, 1) aims at eta1 = sqrt(c)*2^3000. Wherever the clamped point exists as a positive real number but the pair (eta1, c12/eta1) would round to zero or infinity, the split moves eta1 to the nearest point of the feasible segment inside the window of clamp_representable, which keeps both entries normal numbers well short of the overflow threshold. That point is still a member of the family, so the cover stays valid and tight on the off-diagonal; covariance is given up only at blocks whose own point has no representation, and every split that is representable is returned unchanged. This adds a fourth discontinuity, at the edge of the element type's range.

The three families above have no point to clamp: there the split throws, since every pair returned here is a cover. Entries that are already non-finite are returned as IEEE arithmetic gives them, which is what check=false asks for.

DerivativeCovers.clamp_representable — Method
clamp_representable(eta1, c12) -> eta1

eta1 clamped to the window [max(floatmin(F), c12/U), min(U, c12/floatmin(F))], on which both eta1 and c12/eta1 lie in [floatmin(F), U]. F is the type of eta1, and U = 2^(exponent(floatmax(F)) ÷ 2), which is 2^511 for Float64. For a finite positive c12 the window is never empty. balanced_split clamps to this window and then to the feasible segment, so it lands on their intersection whenever the two meet.

U is set below floatmax(F) because each eta seeds a reverse sweep that adds it to its parent's accumulated weight and multiplies it by partials. A seed at the overflow threshold takes the first such sum to Inf, so U leaves half the exponent range as headroom. The cost falls on the pair's other entry, which becomes c12/U or floatmin(F) rather than its value at the equalizing point. U and floatmin(F) are powers of two, so both bounds are exact.

A type without floatmin, floatmax and exponent is returned unchanged.

DerivativeCovers.cyclic_partition — Method
cyclic_partition(t::Tape, ngroups::Integer) -> groups

Assign node k of t to group 1 + (k-1) % ngroups, a node-granular partition for cover_hybrid.

Excess comes from summing contributions whose covers overlap, and overlapping contributions are typically siblings — the many product terms of a quadratic form, the fan-out of a reduction — which a tape lists consecutively. Dealing them round-robin therefore spreads them across groups, where quadrature combines them. Binning by depth instead (see level_partition) puts every sibling in the same group, so on such programs it recovers little of the quadrature merge.

Siblings absorbed into a single array primitive are siblings this partition cannot separate, since every atom of a node lands in the node's group. Dealing atoms instead — cover_hybrid's integer form, see group_seeds — spreads them whether the program packs them into one primitive or spells them out.

DerivativeCovers.dependency_sweep — Method
dependency_sweep(t::Tape, theta, rho) -> (abar, rbar)

The staged form's propagation of the hard and squared channels, one reverse sweep each:

abar[j]   = theta[j]  + sum_{k : j in P_k} magnitude(∂φ_k/∂v_j)   * abar[k]
rbar[j]^2 = rho[j]^2  + sum_{k : j in P_k} magnitude(∂φ_k/∂v_j)^2 * rbar[k]^2

The hard channel is abs_reverse: seeded with theta from local_covers, its value at the inputs is the sum merge. The squared channel collects the same path contributions in quadrature, holding the root of their sum of squares; seeded with the matching rho from quadrature_seeds, rbar at the inputs is the sign-averaged cover, an estimate of the quadrature merge from below. It accumulates with hypot, so no square is formed. Both channels hold magnitudes: rbar is not an adjoint.

cover_hessian forms both channels within its single fused sweep instead; this form seeds them independently.

DerivativeCovers.dispatchcurvature — Method
dispatchcurvature(f, C::Curvature, ::Type{T})

Call f(C), branching on the built-in Curvature forms over the element type T first.

Tape stores its curvatures in a container with abstract element type, so an interface method invoked on one is a dynamic dispatch — once per node per sweep, which is a large fraction of the sweep's cost. Testing the built-in forms by isa first lets the compiler resolve those calls statically. A form defined elsewhere falls through to the same call, dispatched the ordinary way: this is an optimization for the common cases, not a restriction on which forms are allowed.

T is the element type of the tape the curvature came from, which is the one the elementals of overloads.jl record in; a DeclaredCurvature holds magnitudes, so its form is resolved over magtype(T). A curvature over some other element or matrix type is correct here, just not statically resolved.

C is @nospecialized because specializing on it would defeat the point: a caller that knows the concrete form would compile an instance in which every branch below but one is dead, having already paid the dispatch this ladder exists to avoid. One instance per call site and element type, branching at run time, is the intended shape.

DerivativeCovers.group_seeds — Method
group_seeds(t::Tape, etas, groups::AbstractVector{<:Integer}) -> Theta
group_seeds(t::Tape, etas, ngroups::Integer) -> Theta

Seed weights for the vector-mode reverse sweep, Theta[g, j] = sum over the contributions in group g of the weight each places on node j. Channels index the rows so that the weights of one contribution are contiguous.

The two forms differ in what a group holds. groups[k] assigns tape node k, keeping all of its atoms together, and maximum(groups) sets the channel count. An integer ngroups assigns atoms (see atom_slots): they are numbered in tape order and dealt round-robin, so a node exposing several atoms spreads them over several groups. The channel count is ngroups, capped at natoms(t) since further channels would stay empty.

Since a node's atoms partition its slots, both forms deposit the same total weight and differ only in how they distribute it over channels. Dealing atoms makes the distribution independent of how many atoms one elemental carries, so an array primitive that absorbs several atoms into one node still has them spread across channels. Which atoms share a channel remains a matter of the order they appear in.

With etas from local_covers, column j collects exactly the seeds that abs_reverse propagates into the group partial sums. Theta is in boundtype of the tape's element type.

DerivativeCovers.hessian_bound — Method
hessian_bound(t::Tape, vbar, utilde) -> B

The elementwise bound B = sum_k magnitude(vbar[k]) * sum_{i,j} magnitude(C^k[i,j]) * utilde_i * utilde_j', which satisfies B >= abs.(H) entrywise, in boundtype of the tape's element type. Diagnostic only: B is n × n, and the two inequalities it discards — cancellation along paths (inside each utilde) and cancellation across elementals — are exactly the excess this bound trades for its cost.

Each node's term is accumulated by bound_contribution!, which every Curvature supplies in the form its structure allows. A DeclaredCurvature node contributes its declared bound s[i]*s[j] >= abs(C[i, j]), so B >= abs.(H) remains valid conditional on the declaration.

DerivativeCovers.intermediate_gradients — Method
intermediate_gradients(t::Tape) -> u

DerivativeCovers.level_partition — Method

Assign each node of t to one of ngroups groups by binning node_levels into contiguous depth bands. DerivativeCovers.live_nodes — Method

Which nodes of t have an intermediate gradient that is not identically zero. live[k] is false exactly when every path from the inputs to node k passes through a recorded first partial that is exactly zero (whose magnitude is zero), and then ∇v_k is the zero vector in any arithmetic: every term of every path product carries an exact zero factor.

DerivativeCovers.local_covers — Method
local_covers(t::Tape, vbar; check::Bool=true, scales=nothing, ratio=nothing) -> (etas, theta, nguarded)

DerivativeCovers.marginal_weights — Method
marginal_weights(t::Tape, outidxs::AbstractVector{<:Integer}, b::AbstractVector) -> a
marginal_weights(Utilde::AbstractMatrix, b::AbstractVector) -> a

The output weights a_k = ∑_j Ũ_kj / b_j — the row marginal of the surrogate weighted by the current input cover b. Each term of the sum already certifies its own entry (a_k b_j ≥ Ũ_kj), so (a, b) is a valid cover of the surrogate for any positive b.

This is the covariant output-weighting rule: under an output rescaling r → diag(c)*r it picks up exactly diag(c), and under an input rescaling x → diag(d)*x (with b → diag(d)⁻¹*b alongside) it is exactly invariant — each term Ũ_kj/b_j carries the units of r_k alone. The bare row marginal ∑_j Ũ_kj lacks the second property, and the value rule a_k = |r_k| degenerates wherever residuals vanish.

The tape method costs one O(L) abs_forward sweep seeded 1/b_j at the inputs, never forming Ũ. The sweep runs in ExpScaled, so no node along a path overflows or underflows; a returned weight outside the normal range of its type is an error. A zero b_j is accepted only for an input no output depends on: it contributes nothing to any marginal. A zero b_j on an input that does reach an output is an error — no output weighting can restore validity there.

maxpath_forward(t::Tape, d) -> TopTwo

DerivativeCovers.maxpath_rowcorrelation — Method
maxpath_rowcorrelation(t::Tape, outidx::Integer, d; check=true, scales=nothing, ratio=nothing) -> m

The (max, ×) row statistic of the Hessian at outidx relative to the scales d:

m[i] = max over atoms of smax[i] * max_{l != i} smax[l] / d[l] / d[i],

where an atom's smax[l] = max_{slots} eta[slot] * U[parent, l] takes each slot along its largest path (U as in maxpath_forward) and the largest of its slots, and eta are the local covers of local_cover_slots under the same scales and ratio the cover sweeps use.

This is the max-merge counterpart of the largest normalized off-diagonal entry in row i of the quadrature merge's surrogate sum_atoms s_atom s_atom', and is at most that entry. It is exact for a sum of squared linear forms written with each input once per form. It is a statistic for starting a metric fit, not a bound, and not a cover. With d covariant (for instance a cover), m is invariant under rescaling of the inputs and of the output. A coordinate with d[i] == 0 neither seeds the forward sweep nor receives a value: m[i] = 0.

Two sweeps: the forward (max, ×) sweep, and one reverse sweep that carries the adjoint and the (max, ×) channel together, O(L) time and memory.

DerivativeCovers.merge_atoms — Method
merge_atoms(t::Tape, etas, u) -> (h_sum, h_quad)

Both merges of the cover atoms, from per-node cover slots etas and an intermediate-gradient channel u. An atom's cover vector is s_atom = sum_{i in atom} etas[k][i] * u[P_k[i]], and the merges are h_sum = sum_atoms s_atom and h_quad[i] = sqrt(sum_atoms s_atom[i]^2).

DerivativeCovers.nls_partition — Method
nls_partition(N, sqidx; ngroups=nothing) -> groups

Node partition for the residuals-as-groups hybrid merge of a least-squares loss tape with N nodes and residual-square nodes sqidx. Each residual square is placed in a group of its own (ngroups === nothing, one group per residual, giving the exact Gauss–Newton diagonal in quadrature) or spread cyclically across ngroups groups (a cheaper upper bound). Every other node — the residual-curvature subgraph — is placed in one further group, so its second-order contribution is summed there and combined in quadrature with the Gauss–Newton groups.

That last group is always occupied, so maximum(groups) - 1 recovers the number of residual groups even when ngroups exceeds the residual count.

DerivativeCovers.quadrature_surrogate — Method

The m × n quadrature counterpart of jacobian_surrogate: R[k, j] is the 2-norm, over the paths from input j to output k, of the product of the local partial magnitudes along each path, R_kj = sqrt(∑_paths ∏ abs(d)^2). DerivativeCovers.tape_potentials — Method
tape_potentials(t::Tape, outidxs::AbstractVector{<:Integer}; root=nothing, cgiters=0)
    -> (; theta, live, roots, nties)

Log-scale potentials on the live tape graph: one number per node, least-squares-fitting the slot equations θ_child - θ_parent = log|d|. exp(θ) at the output nodes is the start balance_cover uses for start = :logscale on a tape, because rescaling a node's value by s shifts its potential by log s and leaves every difference within a component covariant.

A node is live when it lies on some input-to-output path whose local derivatives are all nonzero; live is that mask over the tape's nodes, and theta is NaN outside it. The live nodes and slots form an undirected graph (parallel slots counted separately) whose components are rooted at their node of maximum undirected degree, lowest node index on ties. roots lists those node indices and nties[c] how many nodes of component c share the root's degree, so a caller can see when the root came down to the index rather than the graph. root overrides the rule with a node index or a vector of them, at most one per component and each live; components with no supplied root keep the default. A supplied root breaks no tie, so its component reports nties[c] = 1.

theta is the breadth-first layer average from each root: θ = 0 at the root, and a node in layer d takes the mean over the slots joining it to layer d-1 of θ_u ± log|d|, + when it is the slot's child. cgiters > 0 refines that with up to this many conjugate-gradient iterations on the normal equations, stopping earlier at a residual floor or at the Laplacian's rank, both of which are invariant under rescaling; past those the iteration only amplifies roundoff along the nullspace. The exact least-squares potentials are independent of the root up to one additive constant per component.

Costs O(L) for cgiters = 0 and O(L) per refinement iteration, with one logarithm per live slot and no derivative evaluations. The fit weights tape slots equally, so like the surrogate itself it depends on how the program is written.

Examples

julia> r(x) = [2 * x[1] * x[2], 4 * x[2] * x[3]];

julia> pot = DerivativeCovers.tape_potentials(tape_function(r, [1.0, 1.0, 1.0])...);

julia> pot.nties, all(isnan, pot.theta[.!pot.live])
([5], true)

MatrixCovers.gramcover — Method
gramcover(t::Tape, outidxs) -> s
gramcover(t::Tape, outidxs, w::AbstractVector) -> s
gramcover(t::Tape, outidxs, W::Diagonal) -> s
gramcover(t::Tape, outidxs, W::AbstractMatrix; v=<symmetric cover of abs.(W)>) -> s

Symmetric cover of the Gram matrix G = J'*W*J of the Jacobian J of the tape outputs outidxs: a nonnegative vector s, one entry per input (1:t.ninputs), with abs(G[i,j]) <= s[i]*s[j] for every pair. Neither J nor G is formed. W defaults to the identity (G = J'*J, the Gauss–Newton matrix), and a vector w means W = Diagonal(w); the weights may have either sign. w, v, and both axes of W are indexed like outidxs, one entry per output.

No cover of J is needed: rescaling the outputs by a diagonal C together with W -> inv(C)*W*inv(C) leaves G unchanged, so the weight alone fixes the output scale.

For any v >= 0 with abs(W[k,l]) <= v[k]*v[l], the result is s = Ũ'*v, where Ũ >= abs.(J) is the absolute-sensitivity surrogate (jacobian_surrogate), and abs(G[i,j]) <= ∑_{k,l} Ũ[k,i]*abs(W[k,l])*Ũ[l,j] <= s[i]*s[j]. For diagonal weights v = sqrt.(abs.(w)) (all ones when unweighted), so an output with zero weight contributes nothing. For a general W the default v is MatrixCovers.symcover of max.(abs.(W), abs.(transpose(W))), which also admits an asymmetric W; a supplied v must be finite, nonnegative, and satisfy abs(W[k,l]) <= v[k]*v[l]. A repeated entry of outidxs is a repeated row of J, and its seeds add.

s comes from one absolute-value reverse sweep seeded v[k] at output node outidxs[k], so it costs O(L) for a tape of length L and never forms Ũ. It sums the weighted rows of Ũ, and for w >= 0 (or no weight) it brackets the per-output quadrature h_gn[j] = sqrt(∑_k w[k]*Ũ[k,j]^2):

h_gn[j] <= s[j] <= sqrt(n_j) * h_gn[j],     n_j = count(>(0), Ũ[:, j]),

where n_j is the number of outputs that input j reaches. h_gn is the minimal symmetric cover of Ũ'*W*Ũ and costs one sweep channel per output, O(m*L). Unweighted, it is the h_gn of cover_nls with ngroups=nothing; with Ũ in hand from a WithDiagnostics result, a diagonal weight gives it as MatrixCovers.gramcover(Utilde, w).

On a tape whose sweeps round upward (see boundtype), such as one recorded over a box of intervals, the seeds and the sweep round upward, and v is raised by the few units in the last place needed for abs(W[k,l]) <= v[k]*v[l] to hold exactly, so s covers G at every point of the box. On any other tape, s carries the roundoff of the sweep without inflation, like the package's other sweep-based covers, so the bound holds to a relative error of a few eps per node on the longest path.

Examples

julia> r(x) = [x[1] * x[2], exp(x[1]) - x[3], x[2] + 2x[3]];

julia> round.(DerivativeCovers.gramcover(t, outidxs); digits=4)   # column sums of abs.(J)
3-element Vector{Float64}:
 3.6487
 1.5
 3.0

julia> round.(DerivativeCovers.gramcover(t, outidxs, [1.0, 0.0, 4.0]); digits=4)   # output 2 dropped
3-element Vector{Float64}:
 2.0
 2.5
 4.0

MatrixCovers.support_components — Method
support_components(t::Tape, outidxs) -> sc::SupportComponents

Connected components of the bipartite support graph of the Jacobian of the outputs outidxs with respect to the tape's inputs: outputs and inputs are the vertices, and each nonzero Ũ_kj is an edge joining output k to input j. The result is a MatrixCovers.SupportComponents whose row axis runs over the outputs in the order of outidxs (1:length(outidxs)) and whose column axis runs over the inputs (1:t.ninputs); query it with rowcomponent, colcomponent, and ncomponents.

This is the tape counterpart of MatrixCovers.support_components(Ũ): it costs O(L) in the tape length and never forms Ũ. A tape edge transmits sensitivity exactly where its first partial is nonzero, so the surrogate's support is carried by those edges alone, and a node is live when it both depends on an input and reaches one of outidxs along them. Any undirected path between live tape nodes splits into ascending and descending runs whose nodes each reach some output, which forces the corresponding bipartite vertices into one component; conversely a support edge is a directed path of live nodes. The undirected components of the live tape graph therefore restrict to the bipartite components exactly.
