Quantities and extension points

These names are public but not exported. Call them with the module prefix, for example DerivativeCovers.cover_ratio. Like exported names, they are covered by the package's compatibility guarantees.

This part of the API contains utilities that operate on covers from any source, along with interfaces for extending the package.

DerivativeCovers.BinaryCurvature — Type
BinaryCurvature(c11, c12, c22) <: Curvature

The second partials [c11 c12; c12 c22] of a binary elemental, slot-aligned with the node's two parents and held inline. Symmetry is structural: one entry stands for both off-diagonal slots.

Inline for the reason UnaryCurvature is.

source
DerivativeCovers.Curvature — Type
Curvature

The second partials ∂²φ_k/∂v_{p_i}∂v_{p_j} of one tape node, in whatever form that node's elemental can supply them. Tape stores one per node.

Cover constructions never need the entries themselves, only bounds on their magnitudes, so a curvature may declare a bound instead of recording a matrix (DeclaredCurvature). The sweeps reach every form through the methods below, which is what lets a new elemental introduce a new form without touching them.

A new subtype must define:

  • cover_slots: the node's rank-1 cover, slot-aligned with its parents.
  • bound_contribution!: the node's term of the elementwise bound B.
  • atom_slots: the parent-slot groups the quadrature merge combines separately. The fallback treats every slot as one atom, which is correct for any curvature whose cover is a single rank-1 term.

A subtype whose entries are recorded exactly may also define:

  • curvature_apply!: the second-order term of a Hessian-vector product.
  • has_exact_partials: false suppresses hvp on any tape containing the node. The fallback is true, so a subtype that declares a bound must override it.

getindex and size are introspection, not part of the contract: a curvature that records no entries has none to report.

source
DerivativeCovers.DeclaredCurvature — Type
DeclaredCurvature(s::AbstractVector) <: Curvature

Declared bound on the second partials of a sub-map output (see submapnode): abs(C[i, j]) <= s[i]*s[j], with the true C not recorded. s is nonnegative and slot-aligned with the node's parents.

Cover constructions consume second partials only through bounds on abs.(C), so the declaration substitutes for a recorded matrix everywhere except hvp, which needs the signed entries and fails fast — hence has_exact_partials is false. Covers built over such a node are valid conditional on the declaration, which is the caller's assertion: nothing on the tape can verify it.

source
DerivativeCovers.DenseCurvature — Type
DenseCurvature(C::AbstractMatrix) <: Curvature

Recorded second partials as an explicit symmetric matrix, slot-aligned with the node's parents.

This is the general form, for a curvature with no structure to exploit and no fixed arity. The elementals of overloads.jl do not use it: a unary or binary block is UnaryCurvature or BinaryCurvature, which hold their entries inline.

The rank-1 cover of a block larger than 2×2 is not a single split, so cover_slots rejects one; the elementwise bound and the Hessian-vector product read any arity. An elemental with more parents whose curvature does have structure supplies a form that carries it, as PairedCurvature and DeclaredCurvature do.

source
DerivativeCovers.NoCurvature — Type
NoCurvature() <: Curvature

The curvature of a node with no second-order term: an input node, a linear n-ary node such as linearnode, or an elemental whose curvature at the recorded point is zero. It contributes to no cover and to no bound, so the sweeps skip it by dispatch rather than by inspecting a matrix of zeros.

source
DerivativeCovers.PairedCurvature — Type
PairedCurvature(q::Int) <: Curvature

Curvature of an inner-product node with q pairs of parent slots ordered (w_1, ..., w_q, x_1, ..., x_q) (see dotnode). Entry (i, j) is 1 when i and j are paired (abs(i - j) == q), the sole nonzero second partials ∂²y/∂w_j∂x_j of y = sum_j w_j*x_j, and 0 otherwise.

The 2q × 2q matrix is never materialized: it has 2q nonzeros, and its block-diagonal structure lets every operation run over the q pairs directly.

source
DerivativeCovers.UnaryCurvature — Type
UnaryCurvature(c) <: Curvature

The second partial φ''(x) of a unary elemental, held inline as the single number it is.

A tape stores its curvatures in a container with abstract element type, so every form is reached through a reference; holding the entry inline rather than in a 1×1 matrix saves the second reference on the way to it, once per node per sweep, and an allocation per node while recording.

source
DerivativeCovers.atom_slots — Method
atom_slots(C::Curvature, nslots) -> atoms

The groups of a node's parent slots that the quadrature merge of cover_hessian combines separately. One atom spanning every slot is correct whenever the node's cover is a single rank-1 term. A PairedCurvature(q) instead forms q atoms, one per pair (j, q+j), matching the block-diagonal structure of its second partials: the atoms it contributes are independent rank-1 terms, not one combined term for the whole node.

DerivativeCovers.bound_contribution! — Method
bound_contribution!(B, C::Curvature, av, ps, utilde)

Accumulate node k's term of the elementwise bound into B: av * sum_{i,j} abs(C[i,j]) * utilde[ps[i]] * utilde[ps[j]]', where av is the absolute adjoint and utilde the forward absolute sensitivities. See hessian_bound.

A DeclaredCurvature contributes its declared bound s[i]*s[j] >= abs(C[i,j]), which factorizes, so its term is the single rank-1 outer product w*w' with w = sum_i s[i]*utilde[ps[i]].

source
DerivativeCovers.bound_ratio — Method
bound_ratio(H, B) -> r

Worst-case ratio max_ij abs(H[i,j]) / B[i,j] over the nonzero entries of H. The elementwise bound holds, B >= abs.(H), exactly when r <= 1.

DerivativeCovers.certifies_dead — Method
certifies_dead(rule::SplitRule) -> Bool

Whether a zero scale reference from rule certifies that the slot's total gradient vanishes identically, so the slot's Hessian contributions are zero and it needs no cover weight. A zero value certifies nothing of the sort, so ValueSplit answers false; a zero absolute sensitivity does, so SensitivitySplit answers true.

With split_scales, this is the pair of methods a new SplitRule must define.

source
DerivativeCovers.check_finite_partials — Method
check_finite_partials(t::Tape, k::Integer, av, c::Tuple)

Throw unless the absolute adjoint av of node k and its covering entries c are all finite, reporting the node's own value and its parents' values.

The covering invariant is a set of comparisons against c, so it cannot fire meaningfully when c is not finite: every comparison against NaN is false and no finite rho covers an infinite entry, so the test would reject a split that is not at fault. A non-finite c says instead that the program is not twice-differentiable where it was recorded — a division by zero, or a power, logarithm or root at its singularity. A non-finite av says the same of a node downstream, whose partials the adjoint has already passed through.

DerivativeCovers.compose_hessian_cover — Function
compose_hessian_cover(hg, gamma, a, b, S=nothing) -> (; h_sum, h_quad)

Symmetric covers of the Hessian of a composite f = g ∘ F at x, with y = F(x), from covers of the pieces:

  • hg: symmetric cover of ∇²g(y) (abs.(∇²g) <= hg*hg'), one entry per output of F;
  • gamma: entrywise bound gamma[k] >= abs(∂g/∂y_k) at y (exact gradient magnitudes qualify);
  • (a, b): Jacobian cover of F at x (abs.(J_F) <= a*b');
  • S: curvature covers with abs.(∇²F_k) <= S[k, :]*S[k, :]' (as declare_submap returns); nothing declares F linear.

The chain rule ∇²f = J_F'*∇²g*J_F + Σ_k (∂g/∂y_k)*∇²F_k bounds entrywise as abs.(∇²f) <= (a⋅hg)² * b*b' + Σ_k gamma[k] * S[k,:]*S[k,:]' — a sum of rank-1 magnitude atoms u_0 = (a⋅hg)*b and u_k = sqrt(gamma[k])*S[k,:]. Both merges are returned: the sum merge h_sum = Σ_α u_α (cross terms are nonnegative slack) and the quadrature merge h_quad[i] = sqrt(Σ_α u_α[i]²) (Cauchy–Schwarz), with h_quad <= h_sum coordinatewise.

For g = 0.5*norm(r)^2 this generic rule gives norm(a, 1)*b for the Gauss–Newton term — weaker than the norm(a, 2)*b of gn_ab, which exploits the repeated J in J'J — so NLS consumers should prefer the specialized object.

DerivativeCovers.compose_jacobian_cover — Method
compose_jacobian_cover(a2, b2, a1, b1) -> (; a, b)

Cover of a product of covered factors: if abs.(J2) <= a2*b2' (m × q) and abs.(J1) <= a1*b1' (q × n), then abs.(J2*J1) <= (b2⋅a1) * a2*b1', so the returned pair a = sqrt(b2⋅a1)*a2, b = sqrt(b2⋅a1)*b1 covers J2*J1 — the Jacobian of a composition F2 ∘ F1 when each factor is covered at the matching point. The inner product b2⋅a1 is invariant under rescalings of the input, middle, and output spaces (b2 and a1 carry inverse middle-space units), and its square root is split onto both sides so the rule commutes with a rescaling of either factor.

Equality holds entrywise for sign-definite rank-1 factors covered exactly; in general the rule pays the same signed-cancellation looseness as any magnitude-level bound on a product.

DerivativeCovers.constantnode — Method
constantnode(t::Tape, c::Real) -> TVar

Record a node with value c, no parents, and empty partials. Its absolute sensitivity is zero, so its Jacobian row vanishes and it contributes no atom to any cover.

Elementals fold a constant operand into the node that consumes it rather than giving it a node (see TVar), so this is reached only at the boundary where a program's outputs become node indices and a constant needs an index to be one: a fixed offset among a program's outputs, such as the unit residual that carries an additive constant of a least-squares loss.

DerivativeCovers.cover_ratio — Method
cover_ratio(H, h) -> r

Worst-case ratio max_ij abs(H[i,j]) / (h[i]*h[j]) over the nonzero entries of H. h is a valid cover of H exactly when r <= 1. Zero entries of H constrain nothing and are skipped; a nonzero entry over a vanishing h[i]*h[j] gives Inf.

source
DerivativeCovers.cover_slots — Method
cover_slots(C::Curvature, rule, t, k, av, scales; check=true) -> Union{Nothing,Vector{T}}

The rank-1 cover of node k of t, slot-aligned with its parents: nonnegative rho with rho[i]*rho[j] >= av*abs(C[i,j]), where av is the absolute adjoint abs(vbar[k]). Returns nothing when the node contributes no second-order term.

rho must be a Vector{T} for T = eltype(t): local_cover_slots asserts that type so that the sweeps, which call it once per node, need not box the result.

rule is the SplitRule that breaks the tie at off-diagonal-active blocks and scales its per-node scale references, as split_scales supplies them. check verifies the covering invariant against the recorded entries; a curvature that declares a bound rather than recording entries has nothing to check against.

t and k locate the node for error reporting only. This is the per-node kernel shared by local_covers and the CoverOnly sweep; see local_cover_slots.

source
DerivativeCovers.curvature_apply! — Method
curvature_apply!(vbardot, C::Curvature, ps, bk, dv)

Accumulate the second-order term of a Hessian-vector product into vbardot: vbardot[ps[i]] += bk * sum_j C[i,j] * dv[ps[j]], where bk is the node's adjoint and dv the forward tangents. See hvp.

Defined only for a curvature that records its entries exactly; has_exact_partials reports which do.

DerivativeCovers.declare_submap — Method
declare_submap(F, x0::AbstractVector; rule=ValueSplit()) -> (; y, J, S)

The declaration submapnode consumes, distilled from F's own scratch tape at x0: exact values y = F(x0), the exact signed Jacobian J from per-output reverse sweeps, and curvature covers S whose row k is the sum-merge cover of ∇²F_k, so abs.(∇²F_k) <= S[k, :]*S[k, :]' by cover_hessian's guarantee. F may return a single TVar (declared as one output) or a vector of them; a linear output gets an exactly zero row of S.

Costs O(q*L_F) time — one q-channel adjoint sweep over F's tape plus one absolute sweep per output — once per declaration; the scratch tape is discarded afterwards. The declaration transforms covariantly under rescalings of F's arguments and outputs because each ingredient inherits the covariance of the underlying sweeps, including the zero-parent-value fallback exception of the local tie-break.

rule selects the SplitRule behind the rows of S. The scratch tape's inputs are F's arguments, so a SensitivitySplit here measures sensitivities relative to those arguments and its weights are expressed in their units. This rule and the recording tape's own cover rule are independent: the recording tape consumes S as a fixed bound, so its covers remain valid whatever rule stands behind the declaration, but the exact-minimizer property of SensitivitySplit holds within each tape separately, not across the boundary.

DerivativeCovers.dependency_severity — Method
dependency_severity(h_sum, h_var) -> severity

Per-coordinate ratio h_sum[i] / h_var[i] of the two channels of cover_variance.

A coordinate reached by a single contribution has the two channels agree and a severity of 1; a coordinate whose cover is built by summing many overlapping contributions has the hard channel grow like their sum and the variance channel like their root-sum-square, so the severity grows with the effective overlap multiplicity.

The two channels vanish together — a coordinate carries seed weight through some path in both or in neither — so coordinates with no Hessian dependence get a severity of 1 rather than NaN. A vanishing h_var under a nonzero h_sum is reachable only by underflow, and gives Inf.

source
DerivativeCovers.dotnode — Method
dotnode(ws::AbstractVector{<:TVar}, xs::AbstractVector{<:TVar}) -> TVar

Record an inner-product node y = sum_j w_j*x_j. Parent slots are ordered (w_1, ..., w_q, x_1, ..., x_q), first partials are (x_1, ..., x_q, w_1, ..., w_q), and the second-partial matrix is PairedCurvature(q). Parent slots are independent even when ws and xs share entries (e.g. dotnode(xs, xs)): the decomposition is over slots, not values.

source
DerivativeCovers.equilibrate — Method
equilibrate(J::AbstractMatrix, a::AbstractVector, b::AbstractVector) -> Jhat

The two-sided equilibrated Jacobian Jhat = diag(a)^-1 J diag(b)^-1, in which the cover pair (a, b) becomes the all-ones covering matrix: (a, b) covers J if and only if every entry of Jhat is at most 1 in magnitude. The equilibrated matrix is the scale-invariant object a downstream linear method should see, since it is unchanged by any rescaling of the outputs or inputs that the cover tracks.

A zero weight is admissible only if the row or column it scales vanishes, in which case that row or column of Jhat is zero; otherwise (a, b) does not cover J and an error is thrown.

source
DerivativeCovers.gn_ab — Method
gn_ab(nls::NLSDiagnostics) -> (a, b)

A valid rank-1 Jacobian cover (a, b) — a_k b_j ≥ |J_{kj}| — read off the residual sensitivities of nls: a = ones(m) and b[j] = maximum(Utilde[:, j]), so a_k b_j = b_j ≥ ũ_{rₖ,j} ≥ |J_{kj}|. This is the uniform-weight cover, exposed for cross-checks against a general asymmetric Jacobian cover; the tight symmetric Gauss–Newton cover is nls.h_gn, not the corollary ‖a‖₂ b of this pair.

DerivativeCovers.jacobian_minimax — Method
jacobian_minimax(M; atol=eps(eltype(M))^(3//4)) -> (; a, b, excess)

The exact minimax rank-1 cover of the nonnegative matrix M: a pair a_k * b_j ≥ M_kj whose worst-case excess max_kj (a_k*b_j)/M_kj over the nonzero entries of M is the smallest any rank-1 cover can achieve. The optimal value is classical (tropical spectral theory / max-balancing): it equals the maximum over bipartite cycles of the support — rows k_1, …, k_r and columns j_1, …, j_r, all entries (k_i, j_i) and (k_i, j_{i+1}) nonzero — of the alternating geometric mean

[ (M_{k_1 j_1} ⋯ M_{k_r j_r}) / (M_{k_1 j_2} ⋯ M_{k_r j_1}) ]^{1/r} .

The r = 2 cycles give jacobian_representability; longer cycles can dominate, so this is the exact form of the floor that function only bounds. Every unit cancels around a cycle (each row and column appears once in the numerator and once in the denominator), so excess is dimensionless and the pair is equivariant under M → diag(c)*M*diag(d) modulo the gauge (a, b) → (γa, γ⁻¹b).

Computed by bisection on the log-space excess with Bellman–Ford feasibility (difference constraints log M_kj ≤ log a_k + log b_j ≤ log M_kj + E), O(nnz·(m+n)) per probe; deterministic, no solver. atol is the absolute log-space bisection width — excess is exact to a relative atol and the returned pair attains it. A zero row of M gets a_k = 0, a zero column b_j = 0; both are exact. Unlike balance_cover this minimizes the worst-case excess itself, so it is the tightness yardstick — but the optimum is generally non-unique off the critical cycles, so prefer balance_cover's rules when covariance-by-uniqueness matters.

source
DerivativeCovers.jacobian_ratio — Method

DerivativeCovers.jacobian_representability — Method
jacobian_representability(M) -> excess

A rigorous lower bound on the worst-case excess max_kj (a[k]*b[j]) / M[k,j] of any rank-1 cover a[k]*b[j] ≥ M[k,j] of the nonnegative matrix M: how much looseness rank-1 structure forces, independent of the merge and surrogate. It is √(max 2×2 defect), where a 2×2 submatrix on rows k, k' and columns j, j' (all four entries nonzero) has defect (M_kj*M_k'j') / (M_kj'*M_k'j); any valid rank-1 cover has excess ≥ √defect on that block. A rank-1 M gives exactly 1; block structure (partially separable Jacobians) drives it up.

Computed in O(m²n) from row-pair differences of log M over shared-support columns — a diagnostic. Pass abs.(J) or a surrogate Ũ as M. This is the 2-cycle restriction of the exact forced excess: longer support cycles can dominate it, and jacobian_minimax computes the exact value together with a pair attaining it.

DerivativeCovers.jacobian_shrink — Method
jacobian_shrink(a::AbstractVector, b::AbstractVector, sigma::Real; safety::Real=1) -> (as, bs)

Shrink the cover pair (a, b) by the spectral slack sigma = scaled_singular_value(J, a, b), returning as = sqrt(s)*a and bs = sqrt(s)*b with s = min(1, safety*sigma).

Validity is inherited: abs(J[k,j]) <= sigma * a[k] * b[j] for every k, j, because every entry of the equilibrated Jacobian is bounded by its spectral norm. The slack is split evenly between the two sides so that the shrink commutes with rescaling of the outputs and of the inputs; any other split of s between as and bs is equally valid. The shrink is a strict improvement exactly when safety*sigma < 1; the clamp keeps a spectrally saturated cover (sigma >= 1) from being inflated, which would be valid but looser.

safety inflates sigma before it is used. It must be large enough that safety*sigma is an upper bound on the true spectral norm: with an exact sigma the default 1 is correct, but the power-iteration estimate converges from below and needs safety > 1.

DerivativeCovers.nls_loss_tape — Method
nls_loss_tape(r, x0) -> (t, outidx, residx, sqidx)

Record the least-squares loss f = ½∑ₖ rₖ(x)² at x0, where r maps a vector of TVars to a vector of residual TVars. Returns the Tape, the loss output node index, the node indices residx of the residuals rₖ, and the node indices sqidx of their squares rₖ².

r may return residuals that are input or duplicated nodes; each is squared into its own fresh node, so sqidx has one distinct entry per residual regardless. A constant residual — a fixed offset of the loss, contributing ½c² to f and a zero row to J — gets a node of its own (constantnode); an all-constant residual vector depends on no parameter and is an error.

DerivativeCovers.scaled_singular_value — Method
scaled_singular_value(J::AbstractMatrix, a::AbstractVector, b::AbstractVector) -> sigma
scaled_singular_value(t::Tape, outidxs, a::AbstractVector, b::AbstractVector; maxiter=200, rtol=cbrt(eps(promote_type(eltype(a), eltype(b)))), rng=Xoshiro(0)) -> sigma

Largest singular value of the equilibrated Jacobian Jhat = diag(a)^-1 J diag(b)^-1 (see equilibrate), which measures how loose the cover (a, b) is in the spectral sense: (a, b) is valid iff every entry of Jhat is at most 1 in magnitude, and sigma >= max_kj abs(Jhat[k,j]).

The dense method is exact, and drops zero weights on the same terms as equilibrate.

The tape method is matrix-free: power iteration on Jhat'Jhat driven by jvp and vjp — about two gradients per iteration, O(L) memory — stopped when the estimate changes by less than rtol relative. It requires a and b to be strictly positive. Each iterate norm(Jhat*v) with norm(v) == 1 is a lower bound on sigma and the sequence converges to it from below, so the estimate must carry a safety-factor inflation before it may shrink a cover (see jacobian_shrink). Failure to converge within maxiter is an error, not a silently returned partial result.

source
DerivativeCovers.scaled_spectral_radius — Method
scaled_spectral_radius(H::AbstractMatrix, h::AbstractVector) -> lambda
scaled_spectral_radius(t::Tape, outidx::Integer, h::AbstractVector; maxiter=200, rtol=cbrt(eps(eltype(h))), rng=Xoshiro(0)) -> lambda

Spectral norm of the scaled Hessian Hhat = D^-1 H D^-1, D = diag(h), which measures how loose the cover h is in the spectral sense: h is valid iff every entry of Hhat is at most 1 in magnitude, and lambda >= max_ij abs(Hhat[i,j]).

The dense method is exact. Coordinates with h[i] == 0 are admissible only if row i of H vanishes, in which case they are dropped; otherwise h does not cover H and an error is thrown.

The tape method is matrix-free: power iteration on Hhat driven by hvp, stopped when the estimate changes by less than rtol relative. It requires h to be strictly positive. Each iterate norm(Hhat*v) with norm(v) == 1 is a lower bound on lambda and the sequence converges to it from below, so the estimate must be inflated by a safety factor before it is used to shrink a cover (see spectral_shrink). Failure to converge within maxiter is an error, not a silently returned partial result.

source
DerivativeCovers.spectral_shrink — Method
spectral_shrink(h::AbstractVector, lambda::Real; safety::Real=1) -> hs

Shrink the cover h by the spectral slack lambda = scaled_spectral_radius(H, h), returning hs = sqrt(min(1, safety*lambda)) * h.

Validity is inherited: abs(H[i,j]) <= lambda * h[i] * h[j] for every i, j, because every entry of the symmetric scaled Hessian is bounded by its spectral norm. The shrink is a strict improvement exactly when safety*lambda < 1; the clamp keeps a spectrally saturated cover (lambda >= 1) from being inflated, which would be valid but looser.

safety inflates lambda before it is used. It must be large enough that safety*lambda is an upper bound on the true spectral norm: with an exact lambda the default 1 is correct, but the power-iteration estimate converges from below and needs safety > 1.

DerivativeCovers.submap — Method
submap(F, xs::AbstractVector{<:TVar}; rule=ValueSplit()) -> Vector{TVar}

Record F as a single declared call on the tape of xs: evaluate declare_submap at the parent values and embed the result via submapnode. The recording tape gains one node per output of F — independent of how many operations F performs internally — at the price that exact Hessian-vector products (hvp) become unavailable on that tape. A scalar-valued F yields a one-element vector. rule is passed to declare_submap and governs only the declaration's curvature covers.

DerivativeCovers.submapnode — Function
submapnode(xs::AbstractVector{<:TVar}, y::AbstractVector{<:Real}, J::AbstractMatrix{<:Real},
           S::Union{Nothing,AbstractMatrix{<:Real}}=nothing) -> Vector{TVar}

Record a declared sub-map call y = F(v) as one node per output, without retracing F's internals: node k carries the value y[k], the arguments xs as parents, the exact signed Jacobian row J[k, :] (J[k, i] = ∂F_k/∂v_i at the parent values) as its first partials, and the declared curvature cover S[k, :] as a DeclaredCurvature: abs(∂²F_k/∂v_i∂v_j) <= S[k, i]*S[k, j]. S = nothing, or an all-zero row of S, declares that output linear in the arguments (NoCurvature).

Gradients and every first-order sweep through the call are exact. Hessian covers are valid conditional on the declaration, which is the caller's assertion — nothing on the tape can verify it — and exact Hessian-vector products are unavailable, so hvp throws on any tape containing a declared call. For the covers to stay scale-covariant the declaration must transform as y -> C*y, J -> C*J*inv(D), S -> sqrt.(C)*S*inv(D) under a rescaling v -> D*v of the arguments and a rescaling y -> C*y of the sub-map outputs (a symmetric cover scales as the square root of its output's scale); declare_submap builds declarations with both properties. The covers are then invariant to the output gauge C, which cancels between each output's adjoint and its declared curvature.

DerivativeCovers.tightness — Method
tightness(h, href) -> (max, geomean, nextra)

Compare a cover h against a reference cover href, coordinate by coordinate. max and geomean summarize the profile h[i]/href[i] over the coordinates where href is positive; nextra counts the coordinates the reference leaves at zero but h does not, which are pure looseness and have no finite ratio. Both summaries are NaN when the reference is everywhere zero.

The full per-coordinate profile h ./ href is the anisotropy view: a single scalar hides whether looseness is spread evenly or concentrated on a few coordinates.
