The module

DerivativeCovers.DerivativeCovers — Module
DerivativeCovers

Compute certified rank-1 bounds on Hessians and Jacobians without forming either matrix.

A Hessian cover is a nonnegative vector h satisfying abs(H[i,j]) <= h[i] * h[j] for every entry of H. cover_hessian records a scalar function on a Tape and computes such a cover, together with the gradient, in O(L) work for a tape of length L. The result is deterministic and certified.

A cover is covariant under rescaling: if x -> D*x, then h -> inv(D)*h; if f -> c*f, then h -> sqrt(c)*h. That holds exactly on any program whose blocks all split on parent values carrying a scale of their own. Where one does not, the split falls back on declared input scales and stays covariant when those are rescaled alongside, scales -> D*scales; guards_any_block says whether a given program is in that case.

using DerivativeCovers imports the main entry points and result types. Public utilities such as cover_ratio, tightness, and equilibrate are not exported; call them with the DerivativeCovers. prefix. The DerivativeCovers.Diagnostics submodule provides tools for studying how cover looseness affects downstream algorithms.

Hessian covers

DerivativeCovers.cover_hessian — Function
cover_hessian([mode], t::Tape, outidx::Integer; check=true, scales=nothing, ratio=nothing, channel=AbsoluteTangents())
cover_hessian([mode], f, x0::AbstractVector; check=true, scales=nothing, ratio=nothing, channel=AbsoluteTangents())
cover_hessian(CoverOnly(), t::Tape, vbar::AbstractVector; check=true, scales=nothing, ratio=nothing)

Compute a certified rank-1 cover of a scalar function's Hessian.

Pass either a tape and scalar output node, or a function and evaluation point. The default CoverOnly mode returns a HessianCover containing the gradient, the sum-merge cover, and the uncertified variance channel. WithDiagnostics additionally computes an explicit elementwise bound and a tighter quadrature cover.

The scales keyword declares the input scales the split falls back on where a block's parent values carry none, and ratio the threshold at which it does so; see split_block and split_ratio. Neither affects validity, only which of the valid covers is chosen, and guards_any_block says whether a program consults them at all. check=true verifies the local covering conditions.

The channel keyword chooses which tangents the merges run over; see TangentChannel. The default AbsoluteTangents is what makes the O(L) sweep possible. SignedTangents keeps the tangent signs and gives the tightest cover available at O(n*L), tighter at every coordinate than the default; it is available under WithDiagnostics only.

Two merges are available:

  • sum merge, h_sum = sum_k s_k: the cross terms of (sum_k s_k)(sum_k s_k)' are nonnegative slack;
  • quadrature merge, h_quad[i] = sqrt(sum_atoms s_atom[i]^2): valid by Cauchy–Schwarz, and the minimal cover of the no-cancellation surrogate M = sum_atoms s_atom s_atom'. An atom (see atom_slots) is a whole node for unary and binary elementals and one parent pair for an inner-product node, so an inner-product node contributes q separate terms to the quadrature merge rather than one.

Both satisfy abs.(H) <= h * h'.

The gradient is in the tape's element type T and the covers in magtype(T). T may be a type whose values stand for sets, such as Interval{Float64} from IntervalArithmetic.jl: recording f over a box x0 = interval.(lo, hi) then gives covers (here Vector{Float64}) that hold at every point of the box, and a gradient whose entries enclose the gradient over the box. The sweeps over such a tape round every sum, product and square root upward (see boundtype), so the covers hold exactly; on a tape of points they hold up to the rounding of the sweeps. Control flow in f that the box does not decide, such as a comparison between overlapping intervals, raises an error, as does an elemental evaluated outside its domain somewhere on the box (see check_values).

CoverOnly()

This mode takes one forward pass and one reverse sweep, or O(L) time and memory. The reverse sweep carries the ordinary adjoint, the absolute cover channel, and the variance channel together:

vbar[p_i] += d_i * vbar[k]                              # signed channel: reverse-mode AD
abar[p_i] += magnitude(d_i) * abar[k] + rho_k[i]        # absolute channel: the cover
qbar[p_i] += magnitude(d_i)^2 * qbar[k] + rho_k[i]^2    # variance channel

with rho_k from local_cover_slots. Every channel of node k is final when the sweep reaches it: adjoint flow and theta seeds come only from k's consumers, which follow it on the tape and are processed first. That makes rho_k — which needs the finished vbar[k] — computable in place, and abar[1:ninputs] equal to abs_reverse(t, theta)[1:ninputs] up to roundoff.

abar sums, over every path from a parent slot of a node to an input, the slot's seed times the product of the absolute first partials along the path. qbar sums the squares of the same path contributions, and h_var = sqrt.(qbar[1:ninputs]) is the variance channel of cover_variance: a scale, not a cover.

A program that reaches the declared-scale fallback requires one additional forward sweep.

Passing the node adjoints vbar =adjoints(t, outidx) in place of outidx runs the same sweep without the signed channel, for a caller that already holds the adjoints of a reverse pass. It returns the same HessianCover bit for bit, with grad = vbar[1:ninputs].

WithDiagnostics()

This mode returns a HessianDiagnostics and costs O(n * L) time and O(n^2) memory. With check=true, it also verifies that the diagnostic and fused computations agree — as an equality under AbsoluteTangents, where both routes compute the same merge, and as a domination under SignedTangents, where the absolute route bounds the signed one.

Examples

julia> f(x) = exp(x[1]) + x[1] * x[2]^2;

julia> c = cover_hessian(f, [0.5, 2.0]);

julia> round.(c.h_sum; digits=4)
2-element Vector{Float64}:
 4.1125
 2.4142

julia> round.(c.grad; digits=4)
2-element Vector{Float64}:
 5.6487
 2.0

julia> H = [exp(0.5) 4.0; 4.0 1.0];   # the Hessian of f at [0.5, 2.0]

julia> all(abs.(H) .<= c.h_sum * c.h_sum')
true

DerivativeCovers.cover_hybrid — Function
cover_hybrid(t::Tape, outidx::Integer, ngroups::Integer; check::Bool=true, scales=nothing, ratio=nothing) -> h
cover_hybrid(t::Tape, outidx::Integer, groups::AbstractVector{<:Integer}; check::Bool=true, scales=nothing, ratio=nothing) -> h
cover_hybrid(f, x0::AbstractVector, spec; check::Bool=true, scales=nothing, ratio=nothing) -> h

Compute a Hessian cover by grouping cover contributions: contributions are summed within each group, then the group totals are combined in quadrature.

An integer ngroups groups the tape's cover atoms (see atom_slots), dealing them round-robin. ngroups=1 is the sum merge, and any ngroups at or above natoms(t) gives every atom a group of its own, which is exactly the quadrature merge h_quad of diagnostic cover_hessian. Because atoms rather than nodes are dealt, the whole range between the two merges stays reachable however the program was written: an elemental that carries several atoms — an inner product, a matrix-vector product — spreads them across groups like the scalar chain it stands for.

Alternatively, groups[k] assigns tape node k to a group, holding all of that node's atoms together; cyclic_partition and level_partition build such partitions.

Every grouping produces a valid cover, and one group is always the sum merge. The computation costs O(G * L) time and memory for G groups. scales and ratio govern the split, as in cover_hessian, and check=true verifies local covers.

Examples

The two endpoints, on a tape carrying three atoms:

julia> f(x) = exp(x[1]) + x[1] * x[2]^2;

julia> round.(cover_hybrid(f, [0.5, 2.0], 1); digits=4)   # one group: the sum merge
2-element Vector{Float64}:
 4.1125
 2.4142

julia> round.(cover_hybrid(f, [0.5, 2.0], 3); digits=4)   # a group per atom: the quadrature merge
2-element Vector{Float64}:
 3.1062
 1.7321

DerivativeCovers.cover_variance — Function
cover_variance(t::Tape, outidx::Integer; check::Bool=true, scales=nothing, ratio=nothing) -> VarianceCover
cover_variance(f, x0::AbstractVector; check::Bool=true, scales=nothing, ratio=nothing) -> VarianceCover

Compute a certified sum-merge cover and an inexpensive estimate of the quadrature merge.

Pass either a tape and scalar output node, or a function and evaluation point. The returned VarianceCover contains the gradient, both channels, and their coordinatewise ratio.

Only h_sum is a certified cover; h_var may underestimate the Hessian. Both come from the single reverse sweep of cover_hessian, which returns them as well, so this costs O(L) time and memory, independent of the number of inputs; cover_variance adds the severity. scales and ratio govern the split, as in cover_hessian, and check=true verifies the local covering conditions.

The same channels follow from the staged form: local_covers and variance_seeds supply the seeds of both channels, and dependency_sweep propagates them.

h_sum[i] adds one contribution per pair of a seeded parent slot and a path from that slot to input i: the slot's seed times the product of the absolute first partials along the path. h_var[i]^2 sums the squares of the same contributions. That is the expected square of their sum when each parent slot carries an independent, equiprobable sign, on its first partial and on its seed — the model gramvariance uses. A variable that enters one elemental through two slots is therefore two paths whose contributions combine in quadrature, although in the program they share a sign: x[1] * x[1] seeds each of its two slots with 1, so h_sum = 2 adds them and h_var = √2, while x[1]^2, a unary elemental with a single slot, gives √2 for both. Where such paths reconverge further along, h_var falls below the exact scale: for x[1] * x[1] * x[1] at x = 3, h_var = √15 against sqrt(abs(f''(3))) = √18.

Examples

julia> f(x) = exp(x[1]) + x[1] * x[2]^2;

julia> vc = cover_variance(f, [0.5, 2.0]);

julia> round.(vc.h_sum; digits=4)
2-element Vector{Float64}:
 4.1125
 2.4142

julia> round.(vc.h_var; digits=4)
2-element Vector{Float64}:
 3.1062
 1.7321

julia> round.(vc.severity; digits=4)
2-element Vector{Float64}:
 1.3239
 1.3938

julia> cover_variance(x -> x[1] * x[1], [3.0]).h_sum   # two slots, two paths
1-element Vector{Float64}:
 2.0

julia> cover_variance(x -> x[1] * x[1], [3.0]).h_var ≈ [sqrt(2)]
true

julia> cover_variance(x -> x[1] * x[1] * x[1], [3.0]).h_var ≈ [sqrt(15)]   # |f''| = 18
true

DerivativeCovers.forward_cover — Function
forward_cover(f, x0::AbstractVector; scales=nothing, ratio=nothing, check=true) -> ForwardCover
forward_cover(x::FVar) -> ForwardCover

Compute a certified rank-1 cover of a scalar function's Hessian by propagating it forward, in one pass and with no tape.

f must accept a vector of FVars and return one, using operations FVar supports. Per variable the propagation carries the value, the signed tangent ∇v, a squared cover of ∇²v, and the scalar declared scale sigma; the recursions are

∇v_k    = sum_i d_i * ∇v_i
sigma_k = sum_i magnitude(d_i) * sigma_i
G_k     = sum_i magnitude(d_i) * G_i + sum over atoms of (sum_{i in atom} rho_i * magnitude.(∇v_i))^2

with rho the same local cover a reverse sweep builds, except that the adjoint factor is 1: a forward pass cannot know how the output depends on the node it is at. The cover is sqrt.(G).

The gradient is in the element type T = float(eltype(x0)) and the cover in magtype(T). As for cover_hessian, x0 may be a box of intervals: the gradient then encloses the gradient over the box and the cover holds at every point of it, the propagation rounding its bounds upward (see boundtype). An elemental evaluated outside its domain somewhere on the box is an error (see check_values).

The second form returns the cover of any variable reached along the way, the propagation having maintained the invariant at every one of them, not only at the output.

Computational cost and tightness

O(n*L) time for n inputs and L operations, and O(n) memory per live variable — no tape, and nothing proportional to the length of the program. Its main advantage is therefore the ability to process programs that are too long to record.

The channels are stored in whatever x0 is made of, so a StaticVector point propagates in static arrays and no node allocates at all. That is worth doing for a handful of inputs and not for many: the propagation is then compiled for the exact input count, which for large n costs more in compilation than it saves at run time. A Vector point propagates in Vectors and compiles once for every size.

Currently, the tape-based cover_hessian with SignedTangents is tighter, since it merges the same atoms weighted by exact adjoints rather than by the unsigned path sums a forward pass has to use.

The cover this reaches is exactly the signed-tangent, absolute-adjoint corner of cover_lattice — h_quad_forward — which is therefore what it is tested against. That corner is incomparable with the default h_quad: it keeps every tangent sign and discards every adjoint sign, so which is tighter is a property of the program.

scales and ratio govern the split exactly as in cover_hessian: the propagation carries both of the references split_block reads, so it splits by the same rule a tape does and its cover is comparable with the tape's coordinate by coordinate. See forward_scale. check=true verifies every local cover.

Examples

julia> f(x) = exp(x[1]) + x[1] * x[2]^2;

julia> c = forward_cover(f, [0.5, 2.0]);

julia> round.(c.grad; digits=4)
2-element Vector{Float64}:
 5.6487
 2.0

julia> H = [exp(0.5) 4.0; 4.0 1.0];   # the Hessian of f at [0.5, 2.0]

julia> all(abs.(H) .<= c.h_quad * c.h_quad')
true

DerivativeCovers.cover_lattice — Function
cover_lattice(t::Tape, outidx::Integer; check::Bool=true, scales=nothing, ratio=nothing)
cover_lattice(f, x0::AbstractVector; check::Bool=true, scales=nothing, ratio=nothing)

Compute the same Hessian cover four ways, once for each combination of a signed or absolute tangent channel with a signed or absolute adjoint channel, and return them in a CoverLattice.

Each channel is a place where the construction may discard signs. The tangent channel is either the exact derivatives from tangents or their absolute-value bound from sensitivities; the adjoint channel is either abs.(vbar) from adjoints or the unsigned acheck = abs_reverse(t, e_outidx), whose entry acheck[k] sums prod(abs(∂φ/∂v)) over every path from k to the output and therefore satisfies acheck >= abs.(vbar).

An absolute channel bounds the exact one wherever it cancels, so replacing a signed channel by its absolute counterpart can only inflate the cover. That orders the corners: h_sum_signed and h_quad_signed are the smallest, h_sum_absadj and h_quad_absadj the largest, and the two mixed corners fall between them but are incomparable with each other. The ordering in the adjoint channel relies on the split scaling with the local matrix, which it does: both of its scale references are properties of the parent nodes, and the adjoint enters every entry of the block alike.

Cost is O(n * L) time and O(n^2) memory: two forward channels, two elementwise bounds, and four merges, each of that order. This is a diagnostic — it measures what each sign channel is worth on a given program, which the O(L) production sweeps cannot report.

scales and ratio govern the split, as in cover_hessian; check verifies the local covering conditions and that the forward and reverse sweeps agree on the gradient and on the sum merge.

Examples

julia> f(x) = (d = sin(x[1]) - x[1]; u = d * x[2]; exp(u) - u);

julia> lat = cover_lattice(f, [0.7, 1.3]);

julia> round.(lat.h_quad; digits=4)          # the corner `cover_hessian` computes
2-element Vector{Float64}:
 3.1673
 0.0768

julia> round.(lat.h_quad_signed; digits=4)   # keeping the tangent signs as well
2-element Vector{Float64}:
 0.4854
 0.0768

julia> all(lat.h_quad_signed .<= lat.h_quad)
true

DerivativeCovers.TangentChannel — Type
TangentChannel

Which tangents a cover construction merges over: the exact ones, or an absolute-value bound on them. The built-in channels are AbsoluteTangents, the default, and SignedTangents. Pass one with the channel keyword to cover_hessian.

A channel defines tangent_channel. The choice affects tightness and cost, but not validity: every channel dominates abs.(∇v) entrywise, which is all the merges require.

source
DerivativeCovers.AbsoluteTangents — Type
AbsoluteTangents()

The TangentChannel that merges over sensitivities, the absolute-value bound utilde >= abs.(∇v). This is the default, and the only channel whose sum merge collapses into a single O(L) reverse sweep — the bound is linear in the seeds, so abs_reverse can carry the whole merge (see CoverOnly).

What it gives up is cancellation along the paths from an input to a node, which SignedTangents keeps.

source
DerivativeCovers.SignedTangents — Type
SignedTangents()

The TangentChannel that merges over abs.(∇v) from tangents, the exact gradient magnitudes.

Paired with the signed adjoints every cover already uses, this is the tightest cover of the O(n*L) tier: abs.(∇v) <= utilde entrywise, so it dominates the default channel at every coordinate, and the only cancellation it still discards is the cancellation between elementals, which the triangle inequality over nodes throws away before any channel is chosen.

It costs O(n*L) time and memory, and cannot be cheaper: the merge takes magnitudes of each tangent inside the sum, where nothing is linear in the seeds and no reverse sweep collapses it. So CoverOnly rejects this channel rather than quietly becoming O(n*L).

Least-squares objectives

DerivativeCovers.cover_nls — Function
cover_nls([mode], r, x0; ngroups=nothing, check=true, scales=nothing, ratio=nothing)

Compute covers for the least-squares loss f(x) = ½∑ₖ rₖ(x)² at x0.

r must map a vector of TVars to a vector of residuals. The default CoverOnly mode returns an NLSCover holding a cover h of the full loss Hessian, a cover h_gn of the Gauss–Newton matrix JᵀJ, and the uncertified root-mean-square scales h_var <= h of the full Hessian and h_var_gn <= h_gn of JᵀJ (the latter from gramvariance). WithDiagnostics returns an NLSDiagnostics, which adds the absolute-sensitivity surrogate Utilde for a further O(m * L).

ngroups sets the number of residual channels G, and with it the entire cost of the CoverOnly mode: O(G * L) time and O(G * n) memory. The default nothing gives every residual a channel of its own (G = m), the tightest pair of covers available. A smaller positive integer spreads the residuals cyclically over G channels and sums their sensitivities within a channel before the quadrature merge; both covers remain valid and can only loosen. The two variance scales take one further O(L) sweep and do not depend on G.

scales and ratio govern the split, as in cover_hessian, and reach only the residual-curvature channel, and through it h and h_var: the residual channels carry unit atoms, which admit no split, so none of h_gn, h_var_gn and Utilde depends on them. check=true verifies the local covering conditions, and under WithDiagnostics also verifies h_gn against Utilde.

Examples

julia> r(x) = [x[1] * x[2] - 1.0, exp(x[1]) - 2.0];

julia> nc = cover_nls(r, [0.5, 2.0]);

julia> round.(nc.h; digits=4)
2-element Vector{Float64}:
 2.7014
 0.5

julia> round.(nc.h_gn; digits=4)
2-element Vector{Float64}:
 2.592
 0.5

julia> all(nc.h_gn .<= nc.h)
true

julia> round.(nc.h_var; digits=4)
2-element Vector{Float64}:
 2.7014
 0.5

julia> all(nc.h_var_gn .<= nc.h_var .<= nc.h)
true

DerivativeCovers.gramvariance — Function
gramvariance(t::Tape, outidxs) -> h
gramvariance(t::Tape, outidxs, w::AbstractVector) -> h
gramvariance(t::Tape, outidxs, W::Diagonal) -> h

Root-mean-square column scale of the Gram matrix G = J'*W*J of the Jacobian J of the tape outputs outidxs: a nonnegative vector h, one entry per input (1:t.ninputs), with

h[j] = sqrt(∑_k abs(w[k]) * Ũ⁽²⁾[k,j]),

where Ũ⁽²⁾[k,j] sums, over the paths from input j to output k, the squared product of the local partial magnitudes along the path. W defaults to the identity, and a vector w means W = Diagonal(w), indexed like outidxs; only abs.(w) enters, so an output with zero weight contributes nothing, and a repeated entry of outidxs adds its weights.

Model each parent slot's local partial as carrying an independent, equiprobable sign. Distinct paths then contribute uncorrelated terms, so E[J[k,j]^2] = Ũ⁽²⁾[k,j] and h[j]^2 = E[(J'*abs.(W)*J)[j,j]]: h is the root-mean-square column norm of sqrt.(abs.(W))*J, the column (MINPACK) scaling of the Gram matrix in expectation. The entries of J for distinct outputs are uncorrelated too, so off-diagonal weights contribute nothing to this expectation; a general W::AbstractMatrix is an error. On an interval tape the magnitudes are the largest over the box, so h bounds the pointwise h at every point of the box.

h is a scale, not a cover: where several paths reach one entry of J with the same sign it can fall below that column's norm. Per entry Ũ⁽²⁾ <= Ũ.^2 (a sum of squares is at most the square of the sum), where Ũ is the absolute-sensitivity surrogate (jacobian_surrogate), so

h[j] <= h_gn[j] = sqrt(∑_k abs(w[k]) * Ũ[k,j]^2) <= gramcover(t, outidxs, w)[j].

Unweighted, h_gn is the Gauss–Newton cover of cover_nls. Where each entry of J has a single path, Ũ⁽²⁾ = Ũ.^2 = abs2.(J) on a point tape, and h equals h_gn and the column norms of sqrt.(abs.(W))*J. Rescaling the inputs, x -> D*x, gives h -> inv(D)*h; rescaling the outputs by a diagonal C together with w -> w ./ C.^2 leaves h unchanged.

h comes from one reverse sweep with squared local partials (the variance channel of dependency_sweep, without its linear channel) seeded abs(w[k]) at output node outidxs[k], so it costs O(L) for a tape of length L, where h_gn needs one channel per output. gramvariance! writes h into a supplied vector.

Examples

julia> r(x) = [x[1] * x[2], exp(x[1]) - x[3], x[2] + 2x[3]];

julia> t, outidxs = tape_function(r, [0.5, 2.0, -1.0]);

julia> round.(DerivativeCovers.gramvariance(t, outidxs); digits=4)   # column norms of J
3-element Vector{Float64}:
 2.592
 1.118
 2.2361

julia> round.(DerivativeCovers.gramvariance(t, outidxs, [1.0, 0.0, 4.0]); digits=4)
3-element Vector{Float64}:
 2.0
 2.0616
 4.0

julia> t2, o2 = tape_function(x -> [x[1] * x[1]], [3.0]);   # two paths, J = [6.0;;]

julia> round.(DerivativeCovers.gramvariance(t2, o2); digits=4)   # sqrt(3^2 + 3^2)
1-element Vector{Float64}:
 4.2426

DerivativeCovers.gramvariance! — Function

Jacobian covers

DerivativeCovers.cover_jacobian — Function
cover_jacobian([mode,] t::Tape, outidxs; start=:covariant, rounds=4, a=nothing, check=true)
cover_jacobian([mode,] r, x0::AbstractVector; ...)

Asymmetric rank-1 cover of a vector-valued function's Jacobian: weights with a[k] * b[j] >= abs(J[k,j]). Pass either a tape and its output nodes, or a function and an evaluation point.

a is chosen by the balancing construction: start is :covariant, whose products on the support transform exactly under a rescaling of the program's inputs, outputs and intermediates, or :equal, which is permutation equivariant instead; rounds alternation rounds then refine it, and rounds = nothing runs balance_cover's alternation to convergence instead. Passing a yourself fixes the weights and rules out start and rounds. a must be strictly positive on every output some input reaches and may be zero on the others, which then contribute to no merge.

Modes

  • CoverOnly() (the default) returns a JacobianCover from O(L) sweeps, never forming the surrogate. Checking a pair against the surrogate is what the other mode is for, so check has no effect here; a factor that vanishes on a row or column the program actually uses is an error either way.
  • WithDiagnostics() returns a JacobianDiagnostics: the same a and b_sum, plus the surrogate and the two tighter merges, at O(m * L). check then verifies b_max against the surrogate.

Examples

julia> r(x) = [x[1] * x[2], exp(x[1]) - x[3], x[2] + 2x[3]];

julia> jc = cover_jacobian(WithDiagnostics(), r, [0.5, 2.0, -1.0]; a = ones(3));

julia> round.(jc.b_max; digits=4)
3-element Vector{Float64}:
 2.0
 1.0
 2.0

julia> all(jc.b_max .<= jc.b_quad .<= jc.b_sum)
true

DerivativeCovers.cover_jacobian_hybrid — Function
cover_jacobian_hybrid(t::Tape, outidxs, groups::AbstractVector{<:Integer}; kwargs...) -> (; a, b)
cover_jacobian_hybrid(t::Tape, outidxs, ngroups::Integer; kwargs...) -> (; a, b)
cover_jacobian_hybrid(r, x0::AbstractVector, groups | ngroups; kwargs...) -> (; a, b)

Compute a Jacobian cover by grouping outputs.

groups[k] assigns output k to a group. Absolute sensitivities are summed within each group, then the group totals are combined with max. Alternatively, pass ngroups to assign outputs cyclically.

Every grouping is valid. One group reproduces b_sum; one group per output reproduces b_max. The cost is O(G * L) for G = maximum(groups), without forming the full surrogate.

The output weights are cover_jacobian's, chosen by the same keywords:

  • start: :covariant (the default) or :equal.
  • rounds: alternation rounds refining them, 4 by default.
  • a: fixed weights of your own instead, strictly positive on every output some input reaches and optionally zero on the others. It rules out start and rounds.
  • check = true: verify the returned b against the surrogate, at O(m * L).

Returns the weights used and the grouped merge for them: a[k] * b[j] >= abs(J[k,j]).

Matrix-free products

DerivativeCovers.hvp — Function
hvp(t::Tape, outidx::Integer, v::AbstractVector) -> Hv
hvp(f, x0::AbstractVector, v::AbstractVector) -> Hv
hvp!(Hv, t::Tape, outidx::Integer, v::AbstractVector) -> Hv

Hessian-vector product H*v of the taped program, formed without the Hessian by differentiating the adjoint recursion along v: one forward tangent sweep dv_k = sum_i (∂φ_k/∂v_i) dv_i seeded with v, then one reverse sweep carrying both the adjoints vbar and their tangents,

vbardot_i += (∂φ_k/∂v_i) * vbardot_k + vbar_k * sum_j (∂²φ_k/∂v_i∂v_j) * dv_j.

The curvature term of each node comes from curvature_apply!, which every Curvature supplies in the form its structure allows — a PairedCurvature node reads its 2q nonzeros off the pairs rather than scanning a 2q × 2q matrix, without which a program built from q-long inner products would cost O(q) gradients instead of two. A node whose second partials are only declared (has_exact_partials is false) makes an exact product impossible: hvp throws on any tape containing one, unconditionally, rather than letting success depend on whether the node's adjoint happens to vanish. The tape method of scaled_spectral_radius inherits this restriction; its dense method does not.

Costs about two gradients and O(L) memory.

hvp! writes into Hv, which shares the axes of v. It saves the result allocation only: the two sweeps still allocate their own O(L) working vectors, so it is not allocation-free.

Examples

julia> f(x) = exp(x[1]) + x[1] * x[2]^2;

julia> x0, v = [0.5, 2.0], [1.0, 0.0];

julia> round.(hvp(f, x0, v); digits=4)
2-element Vector{Float64}:
 1.6487
 4.0

julia> h = cover_hessian(f, x0).h_sum;   # the cover bounds the product

julia> all(abs.(hvp(f, x0, v)) .<= h .* (h' * abs.(v)))
true

Measuring and using covers

DerivativeCovers.cover_ratio — Function
cover_ratio(H, h) -> r

The worst-case ratio max_ij abs(H[i,j]) / (h[i]*h[j]) over the nonzero entries of H. The vector h covers H exactly when r <= 1. Zero entries of H impose no constraints and are skipped; a nonzero entry with a zero denominator gives Inf. abs is magnitude, so an H whose entries enclose a set of Hessians (such as an interval matrix) gives the worst ratio over the set.

source
DerivativeCovers.bound_ratio — Function
bound_ratio(H, B) -> r

The worst-case ratio max_ij abs(H[i,j]) / B[i,j] over the nonzero entries of H. The elementwise bound B >= abs.(H) holds exactly when r <= 1.

source
DerivativeCovers.rank1_ratio — Function
rank1_ratio(B, h) -> r

The worst-case ratio max_ij B[i,j] / (h[i]*h[j]) over the nonzero entries of B. The rank-1 cover h*h' dominates the elementwise bound B exactly when r <= 1.

source
DerivativeCovers.tightness — Function
tightness(h, href) -> (max, geomean, nextra)

Compare a cover h against a reference cover href, coordinate by coordinate. max and geomean summarize the profile h[i]/href[i] over the coordinates where href is positive; nextra counts coordinates where the reference is zero but h is not. These coordinates represent pure looseness and have no finite ratio. Both summaries are NaN when the reference is zero everywhere.

The full per-coordinate profile h ./ href is the anisotropy view: a single scalar hides whether looseness is spread evenly or concentrated on a few coordinates.

source
DerivativeCovers.dependency_severity — Function
dependency_severity(h_sum, h_var) -> severity

Per-coordinate ratio h_sum[i] / h_var[i] of the two channels of cover_variance.

A coordinate reached by a single contribution has the two channels agree and a severity of 1; a coordinate whose cover is built by summing many overlapping contributions has the hard channel grow like their sum and the variance channel like their root-sum-square, so the severity grows with the effective overlap multiplicity.

The two channels vanish together — a coordinate carries seed weight through some path in both or in neither — so coordinates with no Hessian dependence get a severity of 1 rather than NaN. A vanishing h_var under a nonzero h_sum is reachable only by underflow, and gives Inf.

source
DerivativeCovers.jacobian_ratio — Function
jacobian_ratio(J, a, b) -> r

Worst-case ratio max_kj abs(J[k,j]) / (a[k]*b[j]) over the nonzero entries of J. (a, b) is a valid asymmetric cover of J exactly when r ≤ 1. Zero entries of J constrain nothing and are skipped; a nonzero entry over a vanishing a[k]*b[j] gives Inf. The asymmetric counterpart of cover_ratio.

DerivativeCovers.jacobian_representability — Function
jacobian_representability(M) -> excess

A rigorous lower bound on the worst-case excess max_kj (a[k]*b[j]) / M[k,j] of any rank-1 cover a[k]*b[j] ≥ M[k,j] of the nonnegative matrix M: how much looseness rank-1 structure forces, independent of the merge and surrogate. It is √(max 2×2 defect), where a 2×2 submatrix on rows k, k' and columns j, j' (all four entries nonzero) has defect (M_kj*M_k'j') / (M_kj'*M_k'j); any valid rank-1 cover has excess ≥ √defect on that block. A rank-1 M gives exactly 1; block structure (partially separable Jacobians) drives it up.

Computed in O(m²n) from row-pair differences of log M over shared-support columns — a diagnostic. Pass magnitude.(J) (which is abs.(J) for a numeric J) or a surrogate Ũ as M. This is the 2-cycle restriction of the exact forced excess: longer support cycles can dominate it, and jacobian_minimax computes the exact value together with a pair attaining it.

DerivativeCovers.jacobian_minimax — Function
jacobian_minimax(M; atol=eps(eltype(M))^(3//4)) -> (; a, b, excess)

The exact minimax rank-1 cover of the nonnegative matrix M: a pair a_k * b_j ≥ M_kj whose worst-case excess max_kj (a_k*b_j)/M_kj over the nonzero entries of M is the smallest any rank-1 cover can achieve. The optimal value is classical (tropical spectral theory / max-balancing): it equals the maximum over bipartite cycles of the support — rows k_1, …, k_r and columns j_1, …, j_r, all entries (k_i, j_i) and (k_i, j_{i+1}) nonzero — of the alternating geometric mean

[ (M_{k_1 j_1} ⋯ M_{k_r j_r}) / (M_{k_1 j_2} ⋯ M_{k_r j_1}) ]^{1/r} .

The r = 2 cycles give jacobian_representability; longer cycles can dominate, so this is the exact form of the floor that function only bounds. Every unit cancels around a cycle (each row and column appears once in the numerator and once in the denominator), so excess is dimensionless and the pair is equivariant under M → diag(c)*M*diag(d) modulo the gauge (a, b) → (γa, γ⁻¹b).

Computed by bisection on the log-space excess with Bellman–Ford feasibility (difference constraints log M_kj ≤ log a_k + log b_j ≤ log M_kj + E), O(nnz·(m+n)) per probe; deterministic, no solver. atol is the absolute log-space bisection width — excess is exact to a relative atol and the returned pair attains it. A zero row of M gets a_k = 0, a zero column b_j = 0; both are exact. Unlike balance_cover this minimizes the worst-case excess itself, so it is the tightness yardstick — but the optimum is generally non-unique off the critical cycles, so prefer balance_cover's rules when covariance-by-uniqueness matters.

DerivativeCovers.scaled_spectral_radius — Function
scaled_spectral_radius(H::AbstractMatrix, h::AbstractVector) -> lambda
scaled_spectral_radius(t::Tape, outidx::Integer, h::AbstractVector; maxiter=200, rtol=cbrt(eps(eltype(h))), rng=Xoshiro(0)) -> lambda

Spectral norm of the scaled Hessian Hhat = D^-1 H D^-1, D = diag(h), which measures how loose the cover h is in the spectral sense: h is valid iff every entry of Hhat is at most 1 in magnitude, and lambda >= max_ij abs(Hhat[i,j]).

The dense method is exact. Coordinates with h[i] == 0 are admissible only if row i of H vanishes, in which case they are dropped; otherwise h does not cover H and an error is thrown.

The tape method is matrix-free: power iteration on Hhat driven by hvp, stopped when the estimate changes by less than rtol relative. It requires h to be strictly positive, and a tape whose element type is its own magtype: power iteration evaluates at a point, so a set-valued tape (such as one recorded on intervals) is an error. Each iterate norm(Hhat*v) with norm(v) == 1 is a lower bound on lambda and the sequence converges to it from below, so the estimate must be inflated by a safety factor before it is used to shrink a cover (see spectral_shrink). Failure to converge within maxiter is an error, not a silently returned partial result.

DerivativeCovers.spectral_shrink — Function
spectral_shrink(h::AbstractVector, lambda::Real; safety::Real=1) -> hs

Shrink the cover h by the spectral slack lambda = scaled_spectral_radius(H, h), returning hs = sqrt(min(1, safety*lambda)) * h.

Validity is inherited: abs(H[i,j]) <= lambda * h[i] * h[j] for every i, j, because every entry of the symmetric scaled Hessian is bounded by its spectral norm. The shrink is a strict improvement exactly when safety*lambda < 1; the clamp keeps a spectrally saturated cover (lambda >= 1) from being inflated, which would be valid but looser.

safety inflates lambda before it is used. It must be large enough that safety*lambda is an upper bound on the true spectral norm: with an exact lambda the default 1 is correct, but the power-iteration estimate converges from below and needs safety > 1.

lambda must bound the scaled norm wherever the cover is meant to hold: for a cover computed over a set of points, such as a box of intervals, that is the supremum over the set. It must be a plain number (its type is its own magtype); a set-valued lambda, such as an interval, is an error.

DerivativeCovers.scaled_singular_value — Function
scaled_singular_value(J::AbstractMatrix, a::AbstractVector, b::AbstractVector) -> sigma
scaled_singular_value(t::Tape, outidxs, a::AbstractVector, b::AbstractVector; maxiter=200, rtol=cbrt(eps(promote_type(eltype(a), eltype(b)))), rng=Xoshiro(0)) -> sigma

Largest singular value of the equilibrated Jacobian Jhat = diag(a)^-1 J diag(b)^-1 (see equilibrate), which measures how loose the cover (a, b) is in the spectral sense: (a, b) is valid iff every entry of Jhat is at most 1 in magnitude, and sigma >= max_kj abs(Jhat[k,j]).

The dense method is exact, and drops zero weights on the same terms as equilibrate.

The tape method is matrix-free: power iteration on Jhat'Jhat driven by jvp and vjp — about two gradients per iteration, O(L) memory — stopped when the estimate changes by less than rtol relative. It requires a and b to be strictly positive, and a tape whose element type is its own magtype: power iteration evaluates at a point, so a set-valued tape (such as one recorded on intervals) is an error. Each iterate norm(Jhat*v) with norm(v) == 1 is a lower bound on sigma and the sequence converges to it from below, so the estimate must carry a safety-factor inflation before it may shrink a cover (see jacobian_shrink). Failure to converge within maxiter is an error, not a silently returned partial result.

DerivativeCovers.jacobian_shrink — Function
jacobian_shrink(a::AbstractVector, b::AbstractVector, sigma::Real; safety::Real=1) -> (as, bs)

Shrink the cover pair (a, b) by the spectral slack sigma = scaled_singular_value(J, a, b), returning as = sqrt(s)*a and bs = sqrt(s)*b with s = min(1, safety*sigma).

Validity is inherited: abs(J[k,j]) <= sigma * a[k] * b[j] for every k, j, because every entry of the equilibrated Jacobian is bounded by its spectral norm. The slack is split evenly between the two sides so that the shrink commutes with rescaling of the outputs and of the inputs; any other split of s between as and bs is equally valid. The shrink is a strict improvement exactly when safety*sigma < 1; the clamp keeps a spectrally saturated cover (sigma >= 1) from being inflated, which would be valid but looser.

safety inflates sigma before it is used. It must be large enough that safety*sigma is an upper bound on the true spectral norm: with an exact sigma the default 1 is correct, but the power-iteration estimate converges from below and needs safety > 1.

sigma must bound the scaled norm wherever the cover is meant to hold: for a cover computed over a set of points, such as a box of intervals, that is the supremum over the set. It must be a plain number (its type is its own magtype); a set-valued sigma, such as an interval, is an error.

DerivativeCovers.equilibrate — Function
equilibrate(J::AbstractMatrix, a::AbstractVector, b::AbstractVector) -> Jhat

The two-sided equilibrated Jacobian Jhat = diag(a)^-1 J diag(b)^-1, in which the cover pair (a, b) becomes the all-ones covering matrix: (a, b) covers J if and only if every entry of Jhat is at most 1 in magnitude. The equilibrated matrix is the scale-invariant object a downstream linear method should see, since it is unchanged by any rescaling of the outputs or inputs that the cover tracks.

A zero weight is admissible only if the row or column it scales vanishes, in which case that row or column of Jhat is zero; otherwise (a, b) does not cover J and an error is thrown.
