DerivativeCovers.DerivativeCovers — Module
DerivativeCovers

Rank-1 covers of a program's Hessian at about twice the cost of a gradient.

A scalar program is recorded on a Tape by running it on TVar inputs; cover_hessian then returns nonnegative vectors h with abs(H[i,j]) <= h[i]*h[j], without ever forming the Hessian H. The covers are deterministic, guaranteed, and exactly covariant under rescaling of the inputs (h -> inv(D)*h when x -> D*x) and of the objective (h -> sqrt(c)*h when f -> c*f). Input covariance holds as stated for the default ValueSplit rule; under SensitivitySplit it holds when the input weights are rescaled alongside (w -> D*w).

The submodule DerivativeCovers.Problems supplies parameterized families of programs, with reference Hessians, for measuring how loose a cover is and what makes it so.

DerivativeCovers.CoverResult — Type
CoverResult

Covers and diagnostics for one taped program, as returned by cover_hessian.

  • grad: the gradient, i.e. the reverse-mode adjoints at the input nodes.
  • B: the elementwise bound B >= abs.(H). A diagnostic, quadratic in n; the production path never forms it.
  • h_sum: the sum merge, h = sum_k s_k.
  • h_quad: the quadrature merge, h[i] = sqrt(sum_atoms s_atom[i]^2), combining per atom_slots atom rather than per node (see cover_hessian).
  • h_sum_rev: h_sum recomputed by a single reverse sweep in absolute-value arithmetic (abs_reverse), equal to h_sum up to roundoff. The production form is paired_reverse, which fuses this sweep with the adjoint sweep.
  • L: the tape length (node count), inputs included.

CoveredPartials(s::Vector{Float64})

Declared bound on the second partials of a sub-map output node (see submapnode): abs(C[i, j]) <= s[i]*s[j], with the true C not recorded. s is nonnegative and slot-aligned with the node's parents. DerivativeCovers.JacobianCover — Type
JacobianCover

Asymmetric rank-1 covers of a Jacobian, as returned by cover_jacobian. For the fixed output weights a, each b satisfies a_k * b_j ≥ |J_kj| for every entry:

  • a: the output weights the covers were built for (ones(m) by default).
  • b_sum: the sum merge b_j = ∑_k Ũ_kj/a_k — the loosest, obtainable at O(L) from one reverse sweep (see cover_jacobian_hybrid with one group).
  • b_quad: the quadrature merge b_j = √(∑_k (Ũ_kj/a_k)²).
  • b_max: the exact minimal b for this a, b_j = max_k Ũ_kj/a_k. Always b_max ≤ b_quad ≤ b_sum coordinatewise.
  • Utilde: the m × n surrogate Ũ (see jacobian_surrogate), a diagnostic.
  • m, n, L: output count, input count, and tape length.

DerivativeCovers.LognormalInflation — Type
LognormalInflation()

Log-factors proportional to abs(z) for i.i.d. standard normal z, rescaled so the largest is the requested peak. The factors are therefore lognormal in shape but exact in magnitude: the draw decides which coordinates are loose and how sharply, never how loose the worst one is.

For large n the maximum of the draw runs well ahead of the bulk, so the profile is a concentrated head over coordinates that stay near 1 — the anisotropy regime seen on the deep and DAG families. Contrast UniformInflation, the plateau regime.

DerivativeCovers.NLSCover — Type
NLSCover

Covers and diagnostics for a least-squares loss f = ½∑ₖ rₖ², as returned by cover_nls.

  • grad: the gradient of the loss at the inputs.
  • h: a valid cover of the full loss Hessian H = JᵀJ + ∑ₖ rₖ ∇²rₖ, obtained by the residuals-as-groups hybrid merge (each residual's Gauss–Newton atom in its own quadrature group, the residual-curvature nodes summed in one further group).
  • h_gn: a valid symmetric cover of the Gauss–Newton matrix JᵀJ, h_gn[j] = √(∑ₖ ũ_{rₖ,j}²). It bounds √(diag(JᵀJ)) entrywise — the certified analog of the GGN diagonal — with equality when no path cancellation occurs (ũ = |J|). Always h_gn[j] ≤ h[j].
  • Utilde: the m × n matrix of residual absolute sensitivities, Utilde[k, j] = ũ_{rₖ,j} ≥ |J_{kj}|. A diagnostic, O(m·L) to form; the accessor gn_ab reads a rank-1 Jacobian cover off it.
  • m: the number of residuals.
  • L: the tape length (node count) of the loss program, inputs included.

DerivativeCovers.SensitivitySplit — Type
SensitivitySplit(w=nothing)

The SplitRule whose scale references are input-weighted absolute sensitivities: sigma_j is the abs_forward sweep seeded with the weights w at the inputs, so sigma_j >= sum_a w[a] * abs(∂v_j/∂x_a) with equality when no path cancellation occurs. w = nothing means unit weights; otherwise w must hold one strictly positive finite entry per input.

The split equalizes rho1*sigma_1 == rho2*sigma_2, clamped to the feasible segment. This is the exact minimizer of the weighted sum-merge objective sum_a w[a]*h_sum[a] over all per-node splits: the sum merge is linear in the per-node weights, so the objective decouples into one term rho1*sigma_1 + rho2*sigma_2 per node, minimized on the feasible segment by exactly this clamped equalization. w is therefore the statement of which cover the rule optimizes — the weighted sum of the input bounds — not a tuning knob.

A zero scale is a certificate here, not a gap: sigma_j == 0 implies every path from the inputs to v_j carries a zero derivative product, so the total gradient of v_j vanishes identically and every Hessian contribution through that slot is exactly zero. Such a dead slot receives no cover weight and the surviving slot covers only its own diagonal; see local_cover_slots. This certificate is what requires w > 0: a zero weight could zero the scale of a live slot and mark it dead falsely.

Covariance: under a rescaling of the intermediate variables the sigmas transform exactly as the values do, so the covariance argument of balanced_split applies unchanged. Under an input rescaling x -> D*x the covers remain exactly covariant when the weights are rescaled alongside, w -> D*w; with w held fixed (the unit default included) the choice of split — never its validity — depends on the units the inputs are expressed in.

Cost: one extra O(L) forward sweep per cover.

DerivativeCovers.SplitRule — Type
SplitRule

Supertype of the policies that choose among the valid rank-1 covers of a single node. An off-diagonal-active 2×2 block confines its cover to a one-parameter family (see balanced_split), and no function of the block can select within it; a SplitRule supplies the scale reference for each parent slot that makes the selection. Concrete rules: ValueSplit (the default) and SensitivitySplit.

The rule enters every cover construction through local_cover_slots; pass it via the rule keyword of cover_hessian, paired_reverse, local_covers, or cover_hybrid. Every rule yields valid covers everywhere — the rules differ in which member of the family they pick, hence in tightness and in continuity with respect to the evaluation point.

DerivativeCovers.Tape — Type
Tape

A Wengert list recorded while a scalar program runs on TVar inputs.

Node k stores its value vals[k], its parent indices parents[k], the first partials ds[k][i] = ∂φ_k/∂v_{p_i}, and the second partials Cs[k], a symmetric ∂²φ_k/∂v_{p_i}∂v_{p_j} in one of three forms:

  • a dense Matrix{Float64}, for unary and binary elementals;
  • a PairedPartials, for an inner-product node (see dotnode): parent slots are ordered (w_1, ..., w_q, x_1, ..., x_q) and the only nonzero entries are the cross terms ∂²y/∂w_j∂x_j = 1;
  • an empty Matrix{Float64}(undef, 0, 0), for a node whose first partials are constant in the inputs (the input nodes themselves, and linear n-ary nodes such as linearnode): it contributes no second-order term to any cover;
  • a CoveredPartials, for a declared sub-map output (see submapnode): the true second partials are not recorded, only the declared rank-1 bound abs(C[i, j]) <= s[i]*s[j].

The first ninputs nodes are the program's inputs; they carry no parents and empty partials. Nodes are appended as the program executes, so they are in topological order: every parent index is smaller than the node's own index.

DerivativeCovers.ValueSplit — Type
ValueSplit()

The SplitRule whose scale references are the parent value magnitudes abs(v_{p_i}): the split equalizes rho1*abs(v_{p_1}) == rho2*abs(v_{p_2}), clamped to the feasible segment. This is the default rule.

The value channel is empty at a parent whose value is exactly zero, and the fallbacks for that case are documented in balanced_split's extended help. A multiplication node whose operands both vanish is the canonical failure: one ulp of input perturbation turns the exact zeros into roundoff residue, and the split is then decided by the ratio of two roundoff-sized values — the cover stays valid but is discontinuous in the evaluation point. SensitivitySplit has no such seam there.

DerivativeCovers.VarianceCover — Type
VarianceCover

The hard and variance channels of one taped program, as returned by cover_variance.

  • grad: the gradient.
  • h_sum: the sum merge — a guaranteed cover of the Hessian.
  • h_var: the variance-channel estimate of the quadrature merge. It satisfies h_var <= h_quad <= h_sum coordinatewise and is not itself a cover: it drops the covariances between reconvergent contributions, so abs(H[i,j]) may exceed h_var[i]*h_var[j].

DerivativeCovers.abs_forward — Method
abs_forward(t::Tape, theta::AbstractVector) -> s

One forward sweep in absolute-value arithmetic, the transpose of abs_reverse: s[k] = theta[k] + sum_i abs(∂φ_k/∂v_{p_i}) * s[p_i] over the parents p_i of node k, in tape order. Seeding theta[j] = 1 at a single input j gives, at every node, the absolute sensitivity of that node to input j — the j-th column of the surrogate Ũ read at the output nodes — and the sweep is linear in the seeds, so any weighted combination of inputs costs the same one O(L) traversal.

DerivativeCovers.abs_reverse — Method
abs_reverse(t::Tape, theta) -> abar

One reverse sweep in absolute-value arithmetic: abar[j] = theta[j] + sum_{k : j in P_k} abs(∂φ_k/∂v_j) * abar[k].

With theta from local_covers, abar[1:t.ninputs] is the sum-merge cover — the whole merge in a single gradient-cost sweep, because sum_k s_k = sum_j theta[j] * utilde_j is linear in the seeds.

DerivativeCovers.adjoints — Method
adjoints(t::Tape, outidxs::AbstractVector{<:Integer}) -> Vbar

Vector-mode reverse-mode adjoints for several outputs at once: Vbar[k, j] = ∂v_{outidxs[k]}/∂v_j, every output k against every node j, all propagated in one traversal. The m × n Jacobian of the outputs with respect to the inputs is Vbar[:, 1:t.ninputs].

Each output owns a row seeded independently, so a repeated entry in outidxs yields identical rows and an input-node entry a unit row. Costs O(m*L) time and memory: a diagnostic path, like sensitivities, for the exact signed Jacobian; the production cover merges seed abs_reverse at the outputs instead and stay O(L)/O(G*L).

DerivativeCovers.anisotropy — Method
anisotropy(f::AbstractVector) -> a

Spread of the inflation factors f, as the log ratio of their largest to their geometric mean. It is zero exactly when every coordinate is inflated alike, and grows as the same peak inflation is concentrated on fewer coordinates: at peak p over n coordinates, UniformInflation gives 0, RampInflation about log(p)/2, and SpikeInflation log(p)*(1 - 1/n).

Unlike the peak, this is a property of the realized profile rather than of the request, so it is the strength axis to plot a consumer's degradation against when the pattern is random.

DerivativeCovers.balance_cover — Method
balance_cover(t::Tape, outidxs; merge=:sum, arule=:marginal, a0=nothing,
              maxiter=nothing, tol=1e-10, check=true)
balance_cover(r, x0::AbstractVector; kwargs...)
balance_cover(Utilde::AbstractMatrix; merge=:sum, arule=:marginal, a0=nothing,
              maxiter=nothing, tol=1e-10)

Balanced asymmetric cover (a, b): choose the output weights a by alternation, then pair them with the merge b-step b_j = ∑_k Ũ_kj/a_k (:sum; :quad and :max combine the same terms in quadrature or by maximum). Returns (; a, b, iters, delta) — the pair (whose b is the chosen merge for the returned a, so it is a valid cover of the surrogate for any arule), the number of alternation rounds, and the final gauge-invariant change bound delta = max_{kj} |log((a_k b_j)_new / (a_k b_j)_old)|. Throws when delta ≤ tol is not reached within maxiter rounds. Both a-rules are covariant: an output rescaling r → diag(c)*r maps the fixed points by a → diag(c)*a (start a0 transformed alongside), an input rescaling leaves them untouched, and the remaining freedom is the gauge (a, b) → (γa, γ⁻¹b).

maxiter = nothing (the default) selects a per-rule budget: 1000 rounds for the marginal alternation, 10000 for the slower :geomean fit; pass an explicit count to override.

  • arule = :marginal alternates a = marginal_weights(…, b) with the merge b-step. Every iterate is a valid cover — each half-step is valid for any positive other side — so the alternation trades only tightness, never validity. With merge = :sum this is exactly Sinkhorn matrix scaling of Ũ (the b-step normalizes the columns of R_kj = Ũ_kj/(a_k b_j), the a-step its rows), and it inherits Sinkhorn's convergence condition: the sparsity pattern of Ũ must have total support (every nonzero entry on some positive diagonal). Dense patterns qualify; a pattern with a nonzero entry on no positive diagonal (e.g. triangular) makes the iteration drift without bound — every iterate still covers, but the excess grows by a constant per round and the run ends in the non-convergence error. The merge = :max b-step is non-smooth and can instead settle into a limit cycle: the per-round product change plateaus at a positive constant that no larger maxiter reduces (independent of total support). This is detected and reported as a stall, distinct from the drift error; arule = :geomean is the convergent alternative in both cases.
  • arule = :geomean sets a_k to the geometric mean of Ũ_kj/b_j over the nonzero entries of row k, alternating with the same rule on the b-side. In log space this is coordinate descent on the additive two-way fit log Ũ_kj ≈ log a_k + log b_j (row and column effects), so it converges for every sparsity pattern; the intermediate iterates undershoot validity, which the final merge b-step restores. Convergence is linear and can be slow on ill-conditioned supports (chains, wide bands): some sparse patterns need 10^4–10^5 rounds, so raise maxiter when the non-convergence error reports a delta still well above tol.

For m ≠ n the marginal alternation's two normalizations disagree by the factor m/n, a pure gauge drift that is geometric in the round count; each round therefore renormalizes by the power of two nearest a's geometric mean, which is exact in floating point and leaves every product a_k b_j bit-identical.

The tape form with merge = :sum, arule = :marginal (the default) runs both steps as O(L) sweeps (abs_forward seeded 1/b_j at the inputs, abs_reverse seeded 1/a_k at the output nodes) without ever forming Ũ — the production path. Every other combination needs per-output separation, so the tape form forms the surrogate once (O(mL), diagnostic tier) and balances it explicitly. The matrix form accepts any nonnegative magnitude matrix (a surrogate Ũ, or abs.(J)).

check verifies the returned pair covers the surrogate (O(mL); matrix form checks against Utilde directly). A zero row of Ũ (an output insensitive to every input) gets a_k = 0; a zero column (a dead input) gets b_j = 0; both are exact and minimal.

DerivativeCovers.balanced_split — Method
balanced_split(c11, c12, c22, z1, z2) -> (rho1, rho2)

Rank-1 cover of an off-diagonal-active 2×2 block [c11 c12; c12 c22], which requires c12^2 > c11*c22. Returns rho1 >= sqrt(c11) and rho2 >= sqrt(c22) with rho1*rho2 == c12: the cover is exactly tight on the off-diagonal, so no cover of the block is smaller in both entries.

Those constraints leave a one-parameter family. The scale references z1, z2 — one per parent, supplied by a SplitRule: the parent value magnitudes under ValueSplit, the weighted absolute sensitivities under SensitivitySplit — pick a member, giving rho_i the units of sqrt(f)/[v_{p_i}] and making the cover scale-covariant. The result is continuous in all five arguments except where a vanishing scale reference meets a degenerate block; see the extended help.

Extended help

The three constraints confine rho1 to the segment [sqrt(c11), c12/sqrt(c22)] — nonempty precisely because c12^2 > c11*c22 — and fix rho2 = c12/rho1. Every returned cover lies on this segment, which is what makes it entrywise unimprovable: a competitor smaller in both entries would have rho1*rho2 < c12.

The position along the segment is the point that equalizes the value-weighted scales, rho1*z1 == rho2*z2, clamped to the segment when that point falls outside. Covariance follows: under a rescaling v_i -> d_i*v_i of the intermediate variables, c_ij -> c_ij/(d_i*d_j) and z_i -> d_i*z_i, so both endpoints and the equalizing point scale as 1/d_1; clamp is positively homogeneous, so rho_1 -> rho_1/d_1 and rho_2 -> rho_2/d_2.

Clamping is also what keeps the result continuous as a parent value vanishes: the equalizing point runs off to an endpoint, and the endpoint absorbs it. The z1 == 0 and z2 == 0 arms therefore take the limits of that point — the upper endpoint and the lower endpoint respectively — rather than a separate fallback formula.

That reasoning needs the endpoint being approached to be a positive finite scale, and it is not when the corresponding diagonal entry vanishes: c22 == 0 puts the upper endpoint at infinity, c11 == 0 puts the lower endpoint at zero. Nor is there any limit to take when both values vanish at once, since the equalizing point then depends on the ratio z2/z1 alone. In those cases the geometric mean of the endpoints is used, which is covariant and permutation-equivariant; when it too is degenerate the balanced sqrt(c12) is returned.

So the result is continuous except at three families of inputs, where it is the ratio z2/z1 that carries the information and the ratio is unavailable:

  • z1 == 0 with c22 == 0,
  • z2 == 0 with c11 == 0,
  • z1 == z2 == 0, for any block.

A multiplication node with a vanishing operand has c11 == c22 == 0 and meets all three at once. Among the elementals of overloads.jl it is the only source of the first and third: c22 == 0 otherwise requires x^y at x == 1, and ^ rejects a nonpositive base, so it never presents a vanishing z1. The second is also reached by x^y at a zero exponent, where c11 == 0 and z2 == 0 while c22 > 0.

These zero-reference arms concern the value channel: under SensitivitySplit a zero scale certifies a dead slot and local_cover_slots resolves it before this function is reached, so this function only ever receives positive references from that rule.

DerivativeCovers.compose_hessian_cover — Function
compose_hessian_cover(hg, gamma, a, b, S=nothing) -> (; h_sum, h_quad)

Symmetric covers of the Hessian of a composite f = g ∘ F at x, with y = F(x), from covers of the pieces:

  • hg: symmetric cover of ∇²g(y) (abs.(∇²g) <= hg*hg'), one entry per output of F;
  • gamma: entrywise bound gamma[k] >= abs(∂g/∂y_k) at y (exact gradient magnitudes qualify);
  • (a, b): Jacobian cover of F at x (abs.(J_F) <= a*b');
  • S: curvature covers with abs.(∇²F_k) <= S[k, :]*S[k, :]' (as declare_submap returns); nothing declares F linear.

The chain rule ∇²f = J_F'*∇²g*J_F + Σ_k (∂g/∂y_k)*∇²F_k bounds entrywise as abs.(∇²f) <= (a⋅hg)² * b*b' + Σ_k gamma[k] * S[k,:]*S[k,:]' — a sum of rank-1 magnitude atoms u_0 = (a⋅hg)*b and u_k = sqrt(gamma[k])*S[k,:]. Both merges are returned: the sum merge h_sum = Σ_α u_α (cross terms are nonnegative slack) and the quadrature merge h_quad[i] = sqrt(Σ_α u_α[i]²) (Cauchy–Schwarz), with h_quad <= h_sum coordinatewise.

For g = 0.5*norm(r)^2 this generic rule gives norm(a, 1)*b for the Gauss–Newton term — weaker than the norm(a, 2)*b of gn_ab, which exploits the repeated J in J'J — so NLS consumers should prefer the specialized object.

DerivativeCovers.cover_cg — Method
cover_cg(A, b, h; x0=zero(b), itermax=length(b), reltol=sqrt(eps()), reset=16)
    -> (; x, iters, xs)

Conjugate gradients on A*x = b, preconditioned by the cover: the residual is measured in the metric Diagonal(h.^2) that the cover certifies, making the search directions invariant under rescaling of the variables. Returns the final iterate x, the number of iterations iters, and the history xs of every iterate from x0 on, which is what lets a caller judge two different covers by one common yardstick.

A cover that matches A's curvature scales makes the scaled system well conditioned, so the iteration count is a direct read on cover quality: an exact cover of a diagonal A converges in one step, and rescaling that cover by a constant changes nothing, since only the shape of the metric steers the iteration. Iteration stops when the cover-metric residual norm falls to reltol times its initial value, or after itermax iterations — which is the only backstop, as that norm is not monotone in the iteration and a badly scaled metric makes it visibly non-monotone. Every reset iterations the residual is recomputed from x rather than updated, to keep rounding error from accumulating.

Note that the convergence test is itself stated in the cover's metric, so two runs under different covers stop at genuinely different accuracies; comparing them requires a metric fixed outside the iteration, as step_degradation does.

Requires a strictly positive cover. A must be symmetric positive definite for the iteration to be meaningful.

DerivativeCovers.cover_hessian — Method
cover_hessian(t::Tape, outidx::Int; check::Bool=true, rule=ValueSplit()) -> CoverResult

Rank-1 covers of the Hessian of the taped program with output node outidx, or of the scalar program f at x0. rule selects the SplitRule that breaks the tie at off-diagonal-active blocks; every rule yields valid covers. Both merges of the per-node covers s_k = sum_{i in P_k} rho_k[i] * utilde_i are valid covers of the Hessian:

  • sum merge, h_sum = sum_k s_k: the cross terms of (sum_k s_k)(sum_k s_k)' are nonnegative slack;

The returned B, h_quad, and the forward absolute sensitivities behind them cost O(n*L); they are diagnostics. The production path is paired_reverse — one forward pass and one paired reverse sweep, about twice the cost of a gradient — which returns grad and h_sum alone; this function additionally builds the constructive two-sweep form (adjoints, local_covers, abs_reverse) that defines them.

The result is a valid cover for any partition: the group partial sums S_g = sum_{k in g} s_k are nonnegative, so sum_g S_g S_g' >= sum_k s_k s_k' entrywise, and Cauchy–Schwarz makes h[i] = sqrt(sum_g S_g[i]^2) a cover of the left-hand side. DerivativeCovers.jacobian_minimax — Method
jacobian_minimax(M; tol=1e-12) -> (; a, b, excess)

The exact minimax rank-1 cover of the nonnegative matrix M: a pair a_k * b_j ≥ M_kj whose worst-case excess max_kj (a_k*b_j)/M_kj over the nonzero entries of M is the smallest any rank-1 cover can achieve. The optimal value is classical (tropical spectral theory / max-balancing): it equals the maximum over bipartite cycles of the support — rows k_1, …, k_r and columns j_1, …, j_r, all entries (k_i, j_i) and (k_i, j_{i+1}) nonzero — of the alternating geometric mean

[ (M_{k_1 j_1} ⋯ M_{k_r j_r}) / (M_{k_1 j_2} ⋯ M_{k_r j_1}) ]^{1/r} .

The r = 2 cycles give jacobian_representability; longer cycles can dominate, so this is the exact form of the floor that function only bounds. Every unit cancels around a cycle (each row and column appears once in the numerator and once in the denominator), so excess is dimensionless and the pair is equivariant under M → diag(c)*M*diag(d) modulo the gauge (a, b) → (γa, γ⁻¹b).

Computed by bisection on the log-space excess with Bellman–Ford feasibility (difference constraints log M_kj ≤ log a_k + log b_j ≤ log M_kj + E), O(nnz·(m+n)) per probe; deterministic, no solver. tol is the absolute log-space bisection width — excess is exact to a relative tol and the returned pair attains it. A zero row of M gets a_k = 0, a zero column b_j = 0; both are exact. Unlike balance_cover this minimizes the worst-case excess itself, so it is the tightness yardstick — but the optimum is generally non-unique off the critical cycles, so prefer balance_cover's rules when covariance-by-uniqueness matters.

DerivativeCovers.jacobian_shrink — Method

Shrink the cover pair (a, b) by the spectral slack sigma = scaled_singular_value(J, a, b), returning as = sqrt(s)*a and bs = sqrt(s)*b with s = min(1, safety*sigma).

Validity is inherited: abs(J[k,j]) <= sigma * a[k] * b[j] for every k, j, because every entry of the equilibrated Jacobian is bounded by its spectral norm. The slack is split evenly between the two sides so that the shrink commutes with rescaling of the outputs and of the inputs; any other split of s between as and bs is equally valid. Under a rule for which a zero scale certifies a dead slot (SensitivitySplit), a slot with scales[p_i] == 0 gets rho[i] = 0 and its partner covers only its own diagonal. The covering invariant deliberately does not hold slotwise there: every entry it would cover is multiplied by a total gradient that vanishes identically, so the bound B <= sum_k s_k s_k' of cover_hessian is unaffected.

DerivativeCovers.local_covers — Method
local_covers(t::Tape, vbar; check::Bool=true) -> (rhos, theta)

Per-node rank-1 covers. For node k, rhos[k][i] >= 0 satisfies rhos[k][i] * rhos[k][j] >= c^k[i,j] where c^k[i,j] = abs(vbar[k]) * abs(C^k[i,j]); nodes with no second-order contribution get an empty rhos[k]. theta[j] = sum_k rhos[k][i] collects the weight each node receives as a parent, which seeds the reverse sweep of abs_reverse.

A PairedPartials node (an inner product, see dotnode) has c = abs(vbar[k]) on each of its q off-diagonal pairs and zero elsewhere, so its 2q×2q local cover problem separates into q independent 2×2 multiplication-node problems; rhos[k] collects the q per-pair splits from balanced_split, slot-aligned with the node's parents. A node with an empty C (a linear n-ary node, see linearnode) contributes no second-order term and is skipped before the arity check below.

A CoveredPartials node (a declared sub-map output, see submapnode) brings its own rank-1 cover: rhos[k] = sqrt(abs(vbar[k])) * s satisfies the covering invariant against the declared bound s[i]*s[j] >= abs(C[i, j]) by construction, so the arity restriction below does not apply to it. There is no recorded C to check the declaration against, so check cannot audit these nodes — validity is conditional on the declaration.

rule selects the SplitRule that breaks the tie at off-diagonal-active blocks. check verifies the covering invariant at every recorded node.

DerivativeCovers.marginal_weights — Method
marginal_weights(t::Tape, outidxs::AbstractVector{<:Integer}, b::AbstractVector) -> a
marginal_weights(Utilde::AbstractMatrix, b::AbstractVector) -> a

The output weights a_k = ∑_j Ũ_kj / b_j — the row marginal of the surrogate weighted by the current input cover b. Each term of the sum already certifies its own entry (a_k b_j ≥ Ũ_kj), so (a, b) is a valid cover of the surrogate for any positive b.

This is the covariant output-weighting rule: under an output rescaling r → diag(c)*r it picks up exactly diag(c), and under an input rescaling x → diag(d)*x (with b → diag(d)⁻¹*b alongside) it is exactly invariant — each term Ũ_kj/b_j carries the units of r_k alone. The bare row marginal ∑_j Ũ_kj lacks the second property, and the value rule a_k = |r_k| degenerates wherever residuals vanish.

The tape method costs one O(L) abs_forward sweep seeded 1/b_j at the inputs, never forming Ũ. A zero b_j is accepted only for a dead input (one no output depends on): it contributes nothing to any marginal. A zero b_j on a live input is an error — no output weighting can restore validity there.

DerivativeCovers.paired_reverse — Method
paired_reverse(t::Tape, outidx::Int; check::Bool=true) -> (; grad, h)

The exact gradient and the sum-merge cover of cover_hessian, from a single reverse sweep carrying a paired adjoint (vbar[k], abar[k]) per node:

vbar[p_i] += d_i * vbar[k]                       # signed channel: reverse-mode AD
abar[p_i] += abs(d_i) * abar[k] + rho_k[i]       # absolute channel: the cover

with rho_k from local_cover_slots. Both channels of node k are final when the sweep reaches it: adjoint flow and theta seeds come only from k's consumers, which follow it on the tape and are processed first. That makes rho_k — which needs the finished vbar[k] — computable in place, and abar[1:ninputs] equal to abs_reverse(t, theta)[1:ninputs] up to roundoff.

Each node's update consumes only its own partials, its paired adjoint, and the forward-carried scale references of its parents (their values under ValueSplit, one extra absolute forward sweep under SensitivitySplit), so the sweep has the shape of a reverse-mode rule set with a widened cotangent — the form a compiled AD backend can implement, yielding cover and gradient together at gradient cost. rule selects the SplitRule; check verifies the per-node covering invariants, as in local_covers.

DerivativeCovers.psd_excess — Method
psd_excess(A, h, hd) -> (; tau_ref, tau_dist, excess)

How much extra shift an inflated cover forces the PSD boost to apply. tau_ref and tau_dist are the minimal shifts of psd_shift under the reference cover h and its distortion hd, and excess[i] is the ratio of the shift actually applied to coordinate i to the shift the reference boost applies there,

excess[i] = (tau_dist * hd[i]^2) / (tau_ref * h[i]^2)

which is at least 1, and equals 1 for every coordinate exactly when the distortion is uniform: scaling a cover by a constant leaves the shift matrix tau*Diagonal(h.^2) unchanged, so this consumer is blind to isotropic looseness and feels only anisotropy. Summarize the profile with maximum for the worst-hit coordinate. When A is already positive semidefinite both shifts are zero and the excess is 1 throughout.

DerivativeCovers.scaled_singular_value — Method
scaled_singular_value(J::AbstractMatrix, a::AbstractVector, b::AbstractVector) -> sigma
scaled_singular_value(t::Tape, outidxs, a::AbstractVector, b::AbstractVector; maxiter=200, tol=1e-6, rng=MersenneTwister(0)) -> sigma

Largest singular value of the equilibrated Jacobian Jhat = diag(a)^-1 J diag(b)^-1 (see equilibrate), which measures how loose the cover (a, b) is in the spectral sense: (a, b) is valid iff every entry of Jhat is at most 1 in magnitude, and sigma >= max_kj abs(Jhat[k,j]).

The dense method is exact, and drops zero weights on the same terms as equilibrate.

The tape method is matrix-free: power iteration on Jhat'Jhat driven by jvp and vjp — about two gradients per iteration, O(L) memory — stopped when the estimate changes by less than tol relative. It requires a and b to be strictly positive. Each iterate norm(Jhat*v) with norm(v) == 1 is a lower bound on sigma and the sequence converges to it from below, so the estimate must carry a safety-factor inflation before it may shrink a cover (see jacobian_shrink). Failure to converge within maxiter is an error, not a silently returned partial result.

DerivativeCovers.scaled_spectral_radius — Method
scaled_spectral_radius(H::AbstractMatrix, h::AbstractVector) -> lambda
scaled_spectral_radius(t::Tape, outidx::Int, h::AbstractVector; maxiter=200, tol=1e-6, rng=MersenneTwister(0)) -> lambda

Spectral norm of the scaled Hessian Hhat = D^-1 H D^-1, D = diag(h), which measures how loose the cover h is in the spectral sense: h is valid iff every entry of Hhat is at most 1 in magnitude, and lambda >= max_ij abs(Hhat[i,j]).

The dense method is exact. Coordinates with h[i] == 0 are admissible only if row i of H vanishes, in which case they are dropped; otherwise h does not cover H and an error is thrown.

The tape method is matrix-free: power iteration on Hhat driven by hvp, stopped when the estimate changes by less than tol relative. It requires h to be strictly positive. Each iterate norm(Hhat*v) with norm(v) == 1 is a lower bound on lambda and the sequence converges to it from below, so the estimate must be inflated by a safety factor before it is used to shrink a cover (see spectral_shrink). Failure to converge within maxiter is an error, not a silently returned partial result.

softmax(x::AbstractVector)

DerivativeCovers.spectral_shrink — Method
spectral_shrink(h::AbstractVector, lambda::Real; safety::Real=1) -> hs

Shrink the cover h by the spectral slack lambda = scaled_spectral_radius(H, h), returning hs = sqrt(min(1, safety*lambda)) * h.

Validity is inherited: abs(H[i,j]) <= lambda * h[i] * h[j] for every i, j, because every entry of the symmetric scaled Hessian is bounded by its spectral norm. The shrink is a strict improvement exactly when safety*lambda < 1; the clamp keeps a spectrally saturated cover (lambda >= 1) from being inflated, which would be valid but looser.

safety inflates lambda before it is used. It must be large enough that safety*lambda is an upper bound on the true spectral norm: with an exact lambda the default 1 is correct, but the power-iteration estimate converges from below and needs safety > 1.

DerivativeCovers.step_degradation — Method
step_degradation(A, g, h, hd; itermax=length(g), target=1e-6, kwargs...)
    -> (; iters_ref, iters_dist, error_ref, error_dist)

What an inflated cover costs the preconditioned Newton step of cover_cg on A*x = -g. Both runs are judged in the reference cover's metric, against the exact step A \ (-g):

error(x) = norm(h .* (x - A \ (-g))) / norm(h .* (A \ (-g)))

iters_ref and iters_dist are the iterations each run needs to bring that error below target, or nothing if itermax iterations do not suffice — which is itself the degradation, a step budget the distorted cover cannot deliver on. error_ref and error_dist are the errors of the final iterates, and are the reading to take when the budget, not the accuracy, is what is fixed.

Holding the yardstick fixed matters: cover_cg's own convergence test lives in whichever metric it was handed, so a loose cover would otherwise flatter itself by declaring victory sooner. Remaining keyword arguments are forwarded to cover_cg.

DerivativeCovers.submapnode — Function
submapnode(xs::AbstractVector{TVar}, y::AbstractVector{<:Real}, J::AbstractMatrix{<:Real},
           S::Union{Nothing,AbstractMatrix{<:Real}}=nothing) -> Vector{TVar}

Record a declared sub-map call y = F(v) as one node per output, without retracing F's internals: node k carries the value y[k], the arguments xs as parents, the exact signed Jacobian row J[k, :] (J[k, i] = ∂F_k/∂v_i at the parent values) as its first partials, and the declared curvature cover S[k, :] as a CoveredPartials: abs(∂²F_k/∂v_i∂v_j) <= S[k, i]*S[k, j]. S = nothing, or an all-zero row of S, declares that output linear in the arguments (an empty second-partial matrix).

Gradients and every first-order sweep through the call are exact. Hessian covers are valid conditional on the declaration, which is the caller's assertion — nothing on the tape can verify it — and exact Hessian-vector products are unavailable, so hvp throws on any tape containing a declared call. For the covers to stay scale-covariant the declaration must transform as y -> C*y, J -> C*J*inv(D), S -> sqrt.(C)*S*inv(D) under a rescaling v -> D*v of the arguments and a rescaling y -> C*y of the sub-map outputs (a symmetric cover scales as the square root of its output's scale); declare_submap builds declarations with both properties. The covers are then invariant to the output gauge C, which cancels between each output's adjoint and its declared curvature.

MatrixCovers.support_components — Method
support_components(t::Tape, outidxs) -> sc::SupportComponents

Connected components of the bipartite support graph of the Jacobian of the outputs outidxs with respect to the tape's inputs: outputs and inputs are the vertices, and each nonzero Ũ_kj is an edge joining output k to input j. The result is a MatrixCovers.SupportComponents whose row axis runs over the outputs in the order of outidxs (1:length(outidxs)) and whose column axis runs over the inputs (1:t.ninputs); query it with rowcomponent, colcomponent, and ncomponents.

This is the tape counterpart of MatrixCovers.support_components(Ũ): it costs O(L) in the tape length and never forms Ũ. A tape edge transmits sensitivity exactly where its first partial is nonzero, so the surrogate's support is carried by those edges alone, and a node is live when it both depends on an input and reaches one of outidxs along them. Any undirected path between live tape nodes splits into ascending and descending runs whose nodes each reach some output, which forces the corresponding bipartite vertices into one component; conversely a support edge is a directed path of live nodes. The undirected components of the live tape graph therefore restrict to the bipartite components exactly.

Passing the result to gramcover covers a Gram matrix of the Jacobian without ever forming Ũ.
