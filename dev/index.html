DerivativeCovers

DerivativeCovers.DerivativeCovers — Module
DerivativeCovers

Rank-1 covers of a program's Hessian at about twice the cost of a gradient.

A scalar program is recorded on a Tape by running it on TVar inputs; cover_hessian then returns nonnegative vectors h with abs(H[i,j]) <= h[i]*h[j], without ever forming the Hessian H. The covers are deterministic, guaranteed, and exactly covariant under rescaling of the inputs (h -> inv(D)*h when x -> D*x) and of the objective (h -> sqrt(c)*h when f -> c*f). Input covariance holds as stated for the default ValueSplit rule; under SensitivitySplit it holds when the input weights are rescaled alongside (w -> D*w).

using DerivativeCovers brings in the entry points and the types they return, and nothing else. The quantities defined on a cover (cover_ratio, tightness, equilibrate, …) and the surface for adding a new elemental (pushnode!, unarynode, …) are public but unexported, so they are reached by qualification. Tape methods for MatrixCovers.support_components, MatrixCovers.gramcover, and MatrixCovers.gramcover! are defined here, but those functions belong to MatrixCovers: calling them unqualified takes using MatrixCovers as well.

The DerivativeCovers.Diagnostics submodule serves the study of cover quality rather than its use: it supplies the instruments that measure what a loose cover costs a consumer of it. The programs those instruments are exercised on live in the companion package DerivativeCoverProblems, which depends on nothing here.

Quick start

Record a scalar program by running it on TVar inputs, then ask for a cover:

using DerivativeCovers

f(x) = exp(x[1]) + sum(x[i] * x[i+1] for i in 1:length(x)-1)
x0 = [0.5, -1.2, 0.3, 0.8]

c = cover_hessian(f, x0)
c.h_sum
4-element Vector{Float64}:
 2.833218755170708
 1.1454972243679027
 3.632993161855452
 0.6123724356957945

c.h_sum is a nonnegative vector h with abs(H[i,j]) <= h[i]*h[j] for every entry of the Hessian H, which was never formed. The gradient comes along for free:

c.grad
4-element Vector{Float64}:
  0.44872127070012824
  0.8
 -0.3999999999999999
  0.3

That is the whole "do" path: one forward pass and one paired reverse sweep, O(L) in the tape length. cover_jacobian, cover_nls, and cover_variance are the corresponding entry points for vector-valued programs, least-squares losses, and the variance-channel estimate.

Using a cover

A cover is a bound, so what you do with it is bound something. h[i]*h[j] bounds a Hessian entry, norm(h)^2 bounds the spectral radius, and the products h .* d bound the change in the gradient under a step d. hvp, jvp, and vjp supply the exact matrix-free products alongside, each at one sweep.

Two knobs change what you get:

  • Tightness against cost. cover_hybrid and cover_jacobian_hybrid take an integer group count that interpolates between the cheap sum merge and the tighter quadrature merge, at O(G*L).
  • Which cover within the valid family. A node with an active off-diagonal admits a one-parameter family of rank-1 covers and nothing about the node selects within it; a SplitRule supplies the scale reference. ValueSplit (the default) uses parent value magnitudes, SensitivitySplit uses input-weighted sensitivities.

The quantities defined on a cover — cover_ratio, tightness, equilibrate, and the rest — are public but unexported, and live on the Quantities and extension points page.

Studying a cover

The looseness of a cover is itself an object of study, and the package carries the instruments for measuring it. WithDiagnostics asks cover_hessian for the elementwise bound B and the alternative merges alongside the cover, so a ratio can be computed directly:

d = cover_hessian(WithDiagnostics(), f, x0)
DerivativeCovers.cover_ratio(d.B, d.h_sum)
0.4494897427831781

This form costs O(n*L) time and O(n^2) memory — it forms the very matrix the production path exists to avoid — so it is opt-in and never the default.

Beyond that, Diagnostics supplies controlled distortions of a cover and the task-level consumers that reveal what a distortion costs, and the companion package DerivativeCoverProblems supplies the Problem families those instruments are exercised on.

Recording a program

DerivativeCovers.Tape — Type
Tape

A Wengert list recorded while a scalar program runs on TVar inputs.

Node k stores its value vals[k], its parent indices parents[k], the first partials ds[k][i] = ∂φ_k/∂v_{p_i}, and the second partials Cs[k], a symmetric ∂²φ_k/∂v_{p_i}∂v_{p_j} in one of three forms:

  • a dense Matrix{Float64}, for unary and binary elementals;
  • a PairedPartials, for an inner-product node (see dotnode): parent slots are ordered (w_1, ..., w_q, x_1, ..., x_q) and the only nonzero entries are the cross terms ∂²y/∂w_j∂x_j = 1;
  • an empty Matrix{Float64}(undef, 0, 0), for a node whose first partials are constant in the inputs (the input nodes themselves, and linear n-ary nodes such as linearnode): it contributes no second-order term to any cover;
  • a CoveredPartials, for a declared sub-map output (see submapnode): the true second partials are not recorded, only the declared rank-1 bound abs(C[i, j]) <= s[i]*s[j].

The first ninputs nodes are the program's inputs; they carry no parents and empty partials, as does a constant output node (constantnode). Nodes are appended as the program executes, so they are in topological order: every parent index is smaller than the node's own index.

source
DerivativeCovers.TVar — Type
TVar(t::Tape, idx::Integer)
TVar(c::Real)

A scalar in a program being recorded, in one of two states. A recording TVar refers to node idx of the tape t, and every elemental applied to it appends a node. A constant TVar (isconstant) carries a value and no tape: it is what eltype(x)(c) and zero(eltype(x)) produce in generic numeric code, where a typed literal is asked for before any tape is in reach.

Constants are closed under the elementals — an operation on constants alone folds to a constant, and an operation mixing the two records against the recording operand with the constant as a coefficient — so a constant never reaches a node builder. val is the scalar both states carry; for a recording TVar it equals t.vals[idx], which nodes never mutate once pushed.

DerivativeCovers.tape_function — Function
tape_function(f, x0::AbstractVector) -> (tape, outidx)      # scalar output
tape_function(f, x0::AbstractVector) -> (tape, outidxs)     # vector output

Record the program f evaluated at x0. f must accept a vector of TVars and use only the elementals overloaded for TVar. Returns the Tape and, depending on what f returns:

  • a single TVar output: the Int index outidx of the output node;
  • an AbstractVector of TVars: the Vector{Int} of output-node indices outidxs, one per entry. Entries may be input nodes or repeat a node (a duplicated output), and both are kept as given — the indices, not the values, define the outputs. A constant entry gets a node of its own (constantnode) and so a zero Jacobian row; a program whose outputs are all constant depends on none of its inputs and is an error.

Cover entry points

DerivativeCovers.cover_hessian — Function
cover_hessian([mode], t::Tape, outidx::Int; check::Bool=true, rule=ValueSplit())
cover_hessian([mode], f, x0::AbstractVector; check::Bool=true, rule=ValueSplit())

Rank-1 covers of the Hessian of the taped program with output node outidx, or of the scalar program f at x0. mode is CoverOnly(), the default, or WithDiagnostics(); see below for what each returns. rule selects the SplitRule that breaks the tie at off-diagonal-active blocks; every rule yields valid covers. Both merges of the per-node covers s_k = sum_{i in P_k} rho_k[i] * utilde_i are valid covers of the Hessian:

  • sum merge, h_sum = sum_k s_k: the cross terms of (sum_k s_k)(sum_k s_k)' are nonnegative slack;
  • quadrature merge, h_quad[i] = sqrt(sum_atoms s_atom[i]^2): valid by Cauchy–Schwarz, and the minimal cover of the no-cancellation surrogate M = sum_atoms s_atom s_atom'. An atom (see atom_slots) is a whole node for unary and binary elementals and one parent pair for an inner-product node, so an inner-product node contributes q separate terms to the quadrature merge rather than one.

Together they give the chain abs.(H) <= B <= sum_atoms s_atom s_atom' <= h*h' for either h.

CoverOnly()

Returns a HessianCover: the exact gradient and the sum merge, from one forward pass and a single reverse sweep carrying a paired adjoint (vbar[k], abar[k]) per node,

vbar[p_i] += d_i * vbar[k]                       # signed channel: reverse-mode AD
abar[p_i] += abs(d_i) * abar[k] + rho_k[i]       # absolute channel: the cover

with rho_k from local_cover_slots. Both channels of node k are final when the sweep reaches it: adjoint flow and theta seeds come only from k's consumers, which follow it on the tape and are processed first. That makes rho_k — which needs the finished vbar[k] — computable in place, and abar[1:ninputs] equal to abs_reverse(t, theta)[1:ninputs] up to roundoff.

Each node's update consumes only its own partials, its paired adjoint, and the forward-carried scale references of its parents (their values under ValueSplit, one extra absolute forward sweep under SensitivitySplit), so the sweep has the shape of a reverse-mode rule set with a widened cotangent — the form a compiled AD backend can implement, yielding cover and gradient together at about twice the cost of a gradient. check verifies the per-node covering invariants, as in local_covers.

WithDiagnostics()

Returns a HessianDiagnostics, which adds B, h_quad, and h_sum_rev. These and the forward absolute sensitivities behind them cost O(n*L) time and O(n^2) memory; they are diagnostics, and reaching them takes the constructive two-sweep form (adjoints, local_covers, abs_reverse) that defines the covers rather than the fused sweep that computes them. check additionally verifies that the absolute-value reverse sweep reproduces h_sum, and that the CoverOnly() sweep reproduces both the gradient and h_sum.

DerivativeCovers.cover_jacobian — Function
cover_jacobian(t::Tape, outidxs::AbstractVector{<:Integer}; a=nothing, check=true) -> JacobianCover
cover_jacobian(r, x0::AbstractVector; a=nothing, check=true) -> JacobianCover

Asymmetric rank-1 covers of the Jacobian of a vector-valued program: either a tape t with output nodes outidxs, or a program r mapping a vector of TVars to a vector of TVars, evaluated at x0. Returns a JacobianCover carrying the sum, quadrature, and exact (max) merges of the absolute sensitivities for the fixed output weights a.

a must be strictly positive with one entry per output; nothing (the default) uses ones(m). Every merge is a valid cover for any positive a — the choice of a trades tightness between the output and input sides but never validity. check verifies that b_max covers the surrogate.

DerivativeCovers.cover_nls — Function
cover_nls(r, x0; ngroups=nothing, check=true) -> NLSCover

Rank-1 covers of the least-squares loss f = ½∑ₖ rₖ(x)² at x0, where r maps a vector of TVars to the residual vector. Builds the loss tape itself (see nls_loss_tape), so no vector-output recording is required: the residuals are ordinary intermediate nodes.

Returns an NLSCover carrying both a cover h of the full Hessian and a cover h_gn of the Gauss–Newton matrix JᵀJ. h comes from cover_hybrid over the nls_partition; ngroups controls how finely the residual atoms are separated (nothing, the default, gives one group per residual and the tightest Gauss–Newton diagonal at O(m·L); a smaller integer trades tightness for fewer channels). h_gn is formed independently from the residual absolute sensitivities and satisfies h_gn[j] ≤ h[j]; on residuals that are linear in x the two coincide and equal √(diag(JᵀJ)) exactly.

check is forwarded to cover_hybrid to verify the per-node cover invariants.

source
DerivativeCovers.cover_variance — Function
cover_variance(t::Tape, outidx::Int; check::Bool=true, rule=ValueSplit()) -> VarianceCover
cover_variance(f, x0::AbstractVector; check::Bool=true, rule=ValueSplit()) -> VarianceCover

The hard sum-merge cover and the variance-channel estimate of the quadrature merge, for the taped program with output node outidx or for the scalar program f at x0, together with their per-coordinate ratio (see dependency_severity).

Only h_sum is a guaranteed cover; h_var may fall below the Hessian it estimates. The pair costs one adjoint sweep and one two-channel reverse sweep — O(L) time and memory, independent of the input dimension — so the estimate is available wherever the sum merge is, unlike the exact quadrature merge.

rule selects the SplitRule behind the per-node covers; both channels are seeded from the same splits. check verifies the per-node cover invariants.

DerivativeCovers.cover_hybrid — Function
cover_hybrid(t::Tape, outidx::Int, groups::AbstractVector{<:Integer}; check::Bool=true, rule=ValueSplit()) -> h
cover_hybrid(t::Tape, outidx::Int, ngroups::Integer; check::Bool=true, rule=ValueSplit()) -> h
cover_hybrid(f, x0::AbstractVector, spec; check::Bool=true, rule=ValueSplit()) -> h

Cover of the Hessian obtained by summing the per-node covers within each group of groups and combining the groups in quadrature. An integer spec selects a cyclic_partition with that many groups. rule selects the SplitRule behind the per-node covers.

The result is a valid cover for any partition: the group partial sums S_g = sum_{k in g} s_k are nonnegative, so sum_g S_g S_g' >= sum_k s_k s_k' entrywise, and Cauchy–Schwarz makes h[i] = sqrt(sum_g S_g[i]^2) a cover of the left-hand side. Refining a partition can only tighten h, since sqrt((a+b)^2) >= sqrt(a^2 + b^2) for nonnegative a, b; one group reproduces the sum merge and one node per group reproduces the quadrature merge.

Costs one adjoint sweep and one maximum(groups)-channel absolute-value reverse sweep, i.e. O(G*L) time and memory — independent of the input dimension, unlike the exact quadrature merge.

A partition assigns whole nodes to groups, so an inner-product node's atoms (see atom_slots) always travel together within one channel. The finest-partition endpoint on a tape with inner-product nodes is therefore the per-node quadrature merge, bounded below by h_quad from cover_hessian rather than equal to it; validity for every partition, and the interpolation between the sum and quadrature extremes, are unaffected.

DerivativeCovers.cover_jacobian_hybrid — Function
cover_jacobian_hybrid(t::Tape, outidxs, groups::AbstractVector{<:Integer}; a=nothing, check=true) -> b
cover_jacobian_hybrid(t::Tape, outidxs, ngroups::Integer; a=nothing, check=true) -> b

Group-max merge of the absolute sensitivities: partition the m outputs into groups, sum Ũ_kj/a_k within each group, and combine the groups by max. The group partial sums come from a maximum(groups)-channel absolute-value reverse sweep seeded 1/a_k at the output nodes, so the cost is O(G*L) without ever forming the m × n surrogate.

b_j = max_g ∑_{k ∈ group g} Ũ_kj/a_k is a valid cover for every partition: each group sum already dominates every one of its terms Ũ_kj/a_k, and the max preserves that. One group reproduces the sum merge b_sum; one output per group reproduces the exact merge b_max; intermediate partitions interpolate, tightening as the partition is refined. An integer ngroups selects the cyclic partition 1 + (k-1) % ngroups over the outputs.

a is the fixed output weights (nothing uses ones(m)). check verifies b covers the surrogate.

Selecting what cover_hessian returns

CoverOnly()

Ask cover_hessian for a HessianCover: the gradient and the sum-merge cover alone, at O(L). The default.

WithDiagnostics()

Ask cover_hessian for a HessianDiagnostics: the gradient and the sum-merge cover together with the elementwise bound B, the quadrature merge, and the constructive recomputation of the sum merge that cross-checks it. Costs O(n*L) time and O(n^2) memory.

Result types

DerivativeCovers.HessianCover — Type
HessianCover

The gradient and the sum-merge cover of one taped program, as returned by cover_hessian under CoverOnly.

  • grad: the gradient, i.e. the reverse-mode adjoints at the input nodes.
  • h_sum: the sum merge, h_sum = sum_k s_k.
source
DerivativeCovers.HessianDiagnostics — Type
HessianDiagnostics

Covers and diagnostics for one taped program, as returned by cover_hessian under WithDiagnostics. grad and h_sum are the same quantities a HessianCover carries.

  • grad: the gradient, i.e. the reverse-mode adjoints at the input nodes.
  • B: the elementwise bound B >= abs.(H). A diagnostic, quadratic in n; the production path never forms it.
  • h_sum: the sum merge, h_sum = sum_k s_k.
  • h_quad: the quadrature merge, h[i] = sqrt(sum_atoms s_atom[i]^2), combining per atom_slots atom rather than per node (see cover_hessian).
  • h_sum_rev: h_sum recomputed by a single reverse sweep in absolute-value arithmetic (abs_reverse), equal to h_sum up to roundoff. The production form is CoverOnly, which fuses this sweep with the adjoint sweep.
source
DerivativeCovers.JacobianCover — Type
JacobianCover

Asymmetric rank-1 covers of a Jacobian, as returned by cover_jacobian. For the fixed output weights a, each b satisfies a_k * b_j ≥ |J_kj| for every entry:

  • a: the output weights the covers were built for (ones(m) by default).
  • b_sum: the sum merge b_j = ∑_k Ũ_kj/a_k — the loosest, obtainable at O(L) from one reverse sweep (see cover_jacobian_hybrid with one group).
  • b_quad: the quadrature merge b_j = √(∑_k (Ũ_kj/a_k)²).
  • b_max: the exact minimal b for this a, b_j = max_k Ũ_kj/a_k. Always b_max ≤ b_quad ≤ b_sum coordinatewise.
  • Utilde: the m × n surrogate Ũ (see jacobian_surrogate), a diagnostic.
  • m, n: output count and input count.
source
DerivativeCovers.NLSCover — Type
NLSCover

Covers and diagnostics for a least-squares loss f = ½∑ₖ rₖ², as returned by cover_nls.

  • grad: the gradient of the loss at the inputs.
  • h: a valid cover of the full loss Hessian H = JᵀJ + ∑ₖ rₖ ∇²rₖ, obtained by the residuals-as-groups hybrid merge (each residual's Gauss–Newton atom in its own quadrature group, the residual-curvature nodes summed in one further group).
  • h_gn: a valid symmetric cover of the Gauss–Newton matrix JᵀJ, h_gn[j] = √(∑ₖ ũ_{rₖ,j}²). It bounds √(diag(JᵀJ)) entrywise — the certified analog of the GGN diagonal — with equality when no path cancellation occurs (ũ = |J|). Always h_gn[j] ≤ h[j].
  • Utilde: the m × n matrix of residual absolute sensitivities, Utilde[k, j] = ũ_{rₖ,j} ≥ |J_{kj}|. A diagnostic, O(m·L) to form; the accessor gn_ab reads a rank-1 Jacobian cover off it.
  • m: the number of residuals.
source
DerivativeCovers.VarianceCover — Type
VarianceCover

The hard and variance channels of one taped program, as returned by cover_variance.

  • grad: the gradient.
  • h_sum: the sum merge — a guaranteed cover of the Hessian.
  • h_var: the variance-channel estimate of the quadrature merge. It satisfies h_var <= h_quad <= h_sum coordinatewise and is not itself a cover: it drops the covariances between reconvergent contributions, so abs(H[i,j]) may exceed h_var[i]*h_var[j].
  • severity: the per-coordinate ratio h_sum ./ h_var, at least 1, and large exactly on the coordinates whose cover is dominated by reconvergence rather than by Hessian magnitude.

Split rules

DerivativeCovers.SplitRule — Type
SplitRule

Supertype of the policies that choose among the valid rank-1 covers of a single node. An off-diagonal-active 2×2 block confines its cover to a one-parameter family (see balanced_split), and no function of the block can select within it; a SplitRule supplies the scale reference for each parent slot that makes the selection. Concrete rules: ValueSplit (the default) and SensitivitySplit.

The rule enters every cover construction through local_cover_slots; pass it via the rule keyword of cover_hessian, local_covers, or cover_hybrid. Every rule yields valid covers everywhere — the rules differ in which member of the family they pick, hence in tightness and in continuity with respect to the evaluation point.

source
DerivativeCovers.ValueSplit — Type
ValueSplit()

The SplitRule whose scale references are the parent value magnitudes abs(v_{p_i}): the split equalizes rho1*abs(v_{p_1}) == rho2*abs(v_{p_2}), clamped to the feasible segment. This is the default rule.

The value channel is empty at a parent whose value is exactly zero, and the fallbacks for that case are documented in balanced_split's extended help. A multiplication node whose operands both vanish is the canonical failure: one ulp of input perturbation turns the exact zeros into roundoff residue, and the split is then decided by the ratio of two roundoff-sized values — the cover stays valid but is discontinuous in the evaluation point. SensitivitySplit has no such seam there.

source
DerivativeCovers.SensitivitySplit — Type
SensitivitySplit(w=nothing)

The SplitRule whose scale references are input-weighted absolute sensitivities: sigma_j is the abs_forward sweep seeded with the weights w at the inputs, so sigma_j >= sum_a w[a] * abs(∂v_j/∂x_a) with equality when no path cancellation occurs. w = nothing means unit weights; otherwise w must hold one strictly positive finite entry per input.

The split equalizes rho1*sigma_1 == rho2*sigma_2, clamped to the feasible segment. This is the exact minimizer of the weighted sum-merge objective sum_a w[a]*h_sum[a] over all per-node splits: the sum merge is linear in the per-node weights, so the objective decouples into one term rho1*sigma_1 + rho2*sigma_2 per node, minimized on the feasible segment by exactly this clamped equalization. w is therefore the statement of which cover the rule optimizes — the weighted sum of the input bounds — not a tuning knob.

A zero scale is a certificate here, not a gap: sigma_j == 0 implies every path from the inputs to v_j carries a zero derivative product, so the total gradient of v_j vanishes identically and every Hessian contribution through that slot is exactly zero. Such a dead slot receives no cover weight and the surviving slot covers only its own diagonal; see local_cover_slots. This certificate is what requires w > 0: a zero weight could zero the scale of a live slot and mark it dead falsely.

Covariance: under a rescaling of the intermediate variables the sigmas transform exactly as the values do, so the covariance argument of balanced_split applies unchanged. Under an input rescaling x -> D*x the covers remain exactly covariant when the weights are rescaled alongside, w -> D*w; with w held fixed (the unit default included) the choice of split — never its validity — depends on the units the inputs are expressed in.

Cost: one extra O(L) forward sweep per cover.

Matrix-free products

DerivativeCovers.hvp — Function
hvp(t::Tape, outidx::Int, v::AbstractVector) -> Hv
hvp(f, x0::AbstractVector, v::AbstractVector) -> Hv

Hessian-vector product H*v of the taped program, formed without the Hessian by differentiating the adjoint recursion along v: one forward tangent sweep dv_k = sum_i (∂φ_k/∂v_i) dv_i seeded with v, then one reverse sweep carrying both the adjoints vbar and their tangents,

vbardot_i += (∂φ_k/∂v_i) * vbardot_k + vbar_k * sum_j (∂²φ_k/∂v_i∂v_j) * dv_j.

A node with an empty second-partial matrix (see Tape) has no curvature term; the sweep skips it rather than indexing an empty C. A declared sub-map output (submapnode) carries only a bound on its second partials, so an exact product is impossible: hvp throws on any tape containing one, unconditionally, rather than letting success depend on whether the node's adjoint happens to vanish. The tape method of scaled_spectral_radius inherits this restriction; its dense method does not.

Costs about two gradients and O(L) memory.

source
DerivativeCovers.jvp — Function
jvp(t::Tape, outidxs::AbstractVector{<:Integer}, v::AbstractVector) -> Jv
jvp(r, x0::AbstractVector, v::AbstractVector) -> Jv

Jacobian-vector product J*v of the taped vector-valued program, formed without the Jacobian by a single forward tangent sweep dv_k = sum_i (∂φ_k/∂v_i) dv_i seeded with v at the input nodes and read off at outidxs. Costs one sweep and O(L) time and memory, independent of the output count m — unlike adjoints, which is O(m*L).

A repeated entry in outidxs yields an identical entry of Jv.

source
DerivativeCovers.vjp — Function
vjp(t::Tape, outidxs::AbstractVector{<:Integer}, u::AbstractVector) -> Jtu
vjp(r, x0::AbstractVector, u::AbstractVector) -> Jtu

Vector-Jacobian product J'*u of the taped vector-valued program: one reverse adjoint sweep seeded with u[k] at node outidxs[k], read off at the input nodes. Costs one sweep and O(L) time and memory, independent of the output count m.

Outputs that name the same node accumulate their seeds, so a repeated entry in outidxs contributes the sum of the corresponding entries of u — the transpose of jvp's duplicated rows.
